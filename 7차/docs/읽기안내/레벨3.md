# LEVEL 3 - Practitioner

Python3.12와 고정 requirements.txt/requirements_acquire.txt 환경에서 python -B -X utf8 -m rentlab.feature_preflight --features features.json --output new_preflight.json을 실행한다. 기존 파일은 덮어쓰지 않고 sklearn/engine을 불러오거나 학습하지 않는다.

종료0은 validated_input_only, 종료2는 미제공/부적합 입력 또는 보고서 저장 실패다. JSON의 status·errors·manifest/관측/코드 SHA와 특징별 분모를 확인한다. 학습 재개 명령으로 해석하지 않는다. 실제 특징 미제공 검사도 종료2였으며 논문 실측은 없다.

| 범위 | 기존 위험 | 7차 처리 |
|---|---|---|
| CSV 입구 | 중복 머리글·빈 행·행 폭/NUL 오류를 일부 허용 | NUL/원문 구조를 먼저 검사하고 동일 바이트를 파싱 |
| 특징 값 | 유한한 숫자면 음수 개수·소수 시설도 통과 | 정의역·정수 개수·기존 단위 계약 검사 |
| 특징 manifest | feature/source 목록만으로 좁은 스키마 통과 | 전체 관측 칼럼·유효기간·공표시점·중복 ID 검사 |
| H5 재분석 | 직접 writer에서는 고정 버전·인자 비교 누락 | runner와 writer가 공통 설정 검증 사용 |
| 군집 근거 | 저장 예측 cluster 칼럼 누락을 암묵적 강등 | 필수 칼럼으로 검사; 값 미상은 불확실성 미산출 유지 |
| 분석 설정 | 소수 반복수·NaN 군집 수 등이 생성됨 | 개수·시드 타입과 범위 검사 |
| 확정 판정 | 변경된 과학 설정/부족한 재표집 근거를 확정으로 표시 가능 | 고정 조건·반복수·군집 수·유효 반복 근거 검사 |
| 사전 검사 | 외부 특징 기술 검증을 별도로 확인하기 어려움 | 모델 import/fit 없는 CLI와 새 파일 보고서 추가 |

| 확인 | 이번 관측 | 남은 조건 |
|---|---|---|
| 기술 검사 | 161개 통과 | 실측 성능 미측정 |
| 사전 검사 | 정상/미제공/부적합/덮어쓰기 거부 제어 통과 | 계약 조인·실험 전체 readiness 별도 |
| 실제 입력 | 특징 미제공 missing_input 확인 | 최종 특징 동결 미완료 |
| 실행 상태 | 학습 중지 유지 | 역사·물리정답·자원 검증 별도 |
