### 파일·관측·판정의 경계

원문 CSV 구조 → ID와 수치 → 특징 관측의 기간/원천 → 같은 조건의 서울 비교 → 가설 효과·구간 → 화면 근거 검사로 연결된다. 파일 행 수, 특징 관측 수, 계약 수와 단지 군집 수는 서로 다른 분모다.

변화율과 금리는 음수가 정상일 수 있고 지하층 비율도 음수다. 이 값은 보존하면서 거리·인구·시설 개수의 불가능한 값을 거부한다. 현재 자료 통과와 과거 이용가능성은 같은 뜻이 아니다.

| 흐름 | 연결하는 근거 | 구분할 분모·상태 |
|---|---|---|
| CSV → 관측 | 원문 구조·ID·수치·특징 종류 | 파일 행 수와 계약 수는 다름 |
| 관측 → 결합 | 원천·유효기간·시간대 있는 공표시점 | 현재 통과와 과거 이용 가능성은 다름 |
| 서울 비교 → 가설 | 전체 서울 집합과 고정 방법 | 군집 칼럼 누락과 군집 값 미상을 구분 |
| 가설 → 화면 | 과학 조건·반복·군집 근거 | 효과가 있어도 근거 부족이면 확정하지 않음 |
