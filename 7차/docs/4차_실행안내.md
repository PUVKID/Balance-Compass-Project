다운로드 전체행수 일치가 과거 시간 자격이나 좌표의 정확성을 입증하지 않는다. 공식 자료에도 잘못된 좌표가 있을 수 있어 품질 감사를 별도 보존한다. 주소를 비슷한 이름만으로 결합하지 않는다. 단지 좌표의 검증된 연결이 없어 시설 접근성을 전국 계약에 계산했다고 하지 않는다.

## 특징 명세 계약

특징 CSV는 entity_key, feature, value, valid_from, valid_to, published_at, source_id, record_id 열을 가진다. valid_from/to는 YYYY-MM-DD의 반개구간 [from,to), 공개시각은 시간대를 포함한 ISO8601이다. strict_asof는 계약일 KST00시보다 **이전** 공표값 중 유효한 최신1개만 선택한다. 동일 최신시점 후보가 겹치면 임의 선택하지 않는다.

명세 JSON은 status=verified_feature_snapshot, path, sha256, rows, features, key_column, sources를 가진다. key_column은 cluster_id 또는 region이다. sources 각 항목은 source_id, path, sha256, rows, encoding, source_url(HTTPS), acquired_at(시간대포함), status=acquired_current_snapshot을 기록한다. 격리 자료를 허용하지 않는다. 현재 CSV만 검증하며 원본 JSON 등은 별도로 보존한다. 해시/행수 검사만으로 파생값·날짜의 사실성을 자동 인증하지 않으므로 변환 코드·매칭 근거·역사판 확인이 추가로 필요하다.

strict_asof의 특징 결합 함수는 구현됐지만 실행기는 학습/검증/보정 정답의 과거 공개 이력 검증이 미구현인 동안 엄격 실험 실행을 거부한다. 기본은 retrospective_snapshot이며 과거 실시간 재현이라고 쓰지 않는다. 홀드아웃 가격집계는 파생집합 감사가 없어 명시적 거부한다. 가격 유래 특징을 허용된 정보 집합으로 자동 생성하는 기능은 아직 없다.

## 비교와 결과

같은 전세/월세 테스트 계약에서 전체 특징 모델과 기본 특징/정보군 제거 모델을 비교한다. 전체 특징에서 검증 MAE로 Ridge/HGB 중 하나를 고르고 모든 제거 비교는 같은 알고리즘 설정을 쓴다. 결측 대체·범주 인코딩은 학습에서 적합한다. 테스트로 모델을 선택하지 않는다. 기존 H1~H8/15평가와 별도 탐색적 출력이며, 전세·월세 결과를 합산하지 않는다.

예측 CSV, 전체 및 월·지역·매칭 상태별 MAE/RMSE/포함률/구간폭/interval score를 저장한다. 같은 행의 절대오차 차이에 단지 군집9999회 percentile 근사구간을 계산한다. 군집 미상/20개 미만이면 구간을 만들지 않는다. 추가 비교 구간은 점별95%이며 다중비교 동시보장이나 인과효과가 아니다. 학습된 모델을 다시 적합하는 불확실성까지 반영하지 않는다.
