# 10차 검증·사용 안내

Python3.12·고정 requirements·Rust 파서를 준비해 아래 제어 검사를 실행한다. 실제 학습이나 취득은 실행하지 않는다.

```powershell
python -B -X utf8 -m unittest discover -s tests -v
```

178개 통과를 관측했다. 계약·관측·시설의 식별자는 원문을 보존한 문자열이어야 한다. 자동 astype(str)로 오류를 숨기지 말고 원천 명세를 대조한다. 미상 계약 결합키는 그대로 결측으로 유지한다. 출력 특징/출처/결측 표시 열과 기존 열이 겹치면 다른 이름으로 자동 덮어쓰지 않고 실패한다.
