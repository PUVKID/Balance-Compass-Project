# 6차 검증 계약과 실제 관측

6차는 재검토에서 재현된 7개 오류와 산출물 상태 1개를 고쳤다. 실제 학습·새 취득을 실행하지 않았다. 기존 H1–H8, 15개 목표별 평가, 예측구간 오포함률 alpha=0.1 및 가설 family confidence=0.95(명목 가족 오류율 0.05), bootstrap 9,999회, 고정 서울 H5 및 시간 분할은 유지한다.

| 항목 | 이전 취약점 | 6차 처리 |
|---|---|---|
| 예측 원행 | 중복·빈 ID와 건수 불일치가 계산에 유입 | 문자 ID 보존, 목표·분할 간 중복/건수/날짜 검사 |
| 서울 H5 | 직접 재분석에서 일부 서울 또는 다른 도시 허용 | 동일 스냅숏, 전체 서울 테스트 ID 집합 및 정답·날짜·군집 대조 |
| 자료 모드 | 알 수 없는 mode가 합성 판정 제한 우회 | REAL/SYNTHETIC만 수락, 합성 가설 지지 판정 억제 |
| 화면 수치 | 지역 합계·RMSE/MAE·구간 순서 모순 수락 | 지역 가중 일치, RMSE≥MAE, 구간·판정 상태 정합 검사 |
| 공원 ID | 충돌 ID가 하나의 시설처럼 쓰일 위험 | 충돌 원행 모두 보류, 평균·첫 행·최신 행 선택 금지 |
| 철도 | 과거 기준일과 노선 키를 현재 물리역처럼 사용 | 오래된 기준일 표시, 물리역 ID·개통 이력 미확보 차단 |
| 시설 시점 | 미래 설립·승인·불명 기준일의 과거 소급 | 시설별 행 자격 보고서 재계산 및 유효 시점 소급 금지 |
| 산출물 상태 | 전 가설 미측정인데 measured 표시 | JSON과 반환값에 동일한 unmeasured 산출물 상태 저장 |

## 저장 결과 입력

`write_research_results`는 mode, 목표 목록과 분할 건수, 예측 CSV를 계산 전에 검증한다. REAL은 유효한 스냅숏 해시·ID·행 수 근거가 필요하다. 이 형식 검사는 출처 주장이 사실이라는 독립 증명은 아니다. 문자열 source_row_id의 앞자리 0을 보존하며 빈 값·중복과 목표/분할 간 겹침을 거부한다. 실제 읽은 바이트의 SHA-256·크기·행 수를 input_files에 기록한다.

선언한 목표에는 테스트·보정 CSV가 모두 필요하다. 미선언 목표는 미측정으로 남고 해당 CSV가 있으면 오류다. 보정은 2024-07-01~12-31, 테스트는 2025년이다. 서울 H5는 같은 스냅숏·mode와 고정 서울 제외 실행만 비교한다. 일반 결과의 전체 서울 테스트 ID 집합이 정확히 일치해야 하고 보정에 서울이 섞이면 거부한다. paired 정답·지역·날짜 및 양쪽에 있는 군집을 대조한다.

## 표시 수치와 통계 해석

지역 n 합계는 전체 n과 같아야 하고, 전체 MAE와 포함률은 지역 n 가중 평균과 일치해야 한다. RMSE≥MAE, 구간 수치의 동시 존재, 등록된 가설/목표 조합과 상태·판정 조합, 유한하고 순서가 맞는 CI를 요구한다. 부동소수점 일치 허용은 relative=1e-9, absolute=1e-6이며 가설의 과학적 동등성 한계가 아니다. percentile CI가 점추정치를 포함하지 않는 정상 사례는 거부하지 않는다.

MAE=Σ|y−ŷ|/n, RMSE=√(Σ(y−ŷ)²/n), MAE=Σn_g MAE_g/n, coverage=Σn_g coverage_g/n이다. 수식 자체와 가설 문턱은 바꾸지 않았다. 모든 가설 effect가 null이면 산출물도 unmeasured다. SYNTHETIC의 effect가 있어도 논문 지지로 판정하지 않는다. [기존 가설·수식·인용](논문_가설과_수식.md), [확장식](확장분석_수식과해석.md)을 유지하며 이번 검증식에 새 통계 성과나 추가 인용을 주장하지 않는다.

현재 감사는 reference_start=2026-01-01, 연구 종료일 감사는 reference_start=2025-01-01이다. 이 창은 명시적으로 저장한 검사 정책이며 보편적으로 검증된 신선도 기준이 아니다. 행별 사유는 중복될 수 있으므로 사유 건수를 더해 전체 건수로 해석하지 않는다. 적격 일부 행이 존재해도 전체 원천의 all_rows_eligible을 승인하지 않는다.

공원은 중복 원행 2,259행을 모두 보류한다. 현시점 오래된 기준일 6,374행, 설립/고시일 미상 3,468행, 잘못된 좌표 1행과 면적 오류 13행이 있다. 공원 지정고시일은 개장·운영 이력 증거가 아니다. 철도 복합 키 중복 52그룹과 좌표 충돌 12그룹을 별도로 표시하며 노선별 역번호를 물리역 ID로 바꾸지 않는다. KAPT 속성 오류 12행도 보류한다. 학교 현시점 기계 적격 12,004행은 과거 정보 승인이나 전국 완전성의 증거가 아니다.

`historical_availability_proven`과 `source_completeness_proven`은 false로 남는다. 시설·단지 특징 manifest는 quality_reports의 source_id/path/sha256과 원천 CSV를 다시 해시 검사하고 보고서 전체를 재계산한다. 승인 플래그만 편집해 우회할 수 없다. source 종류와 feature 종류도 일치해야 한다. 역사 미입증 시설 값의 valid_from은 감사 as_of 및 KST 취득일 중 늦은 날보다 앞설 수 없다. 현재 자료를 2022–2025년 특징으로 소급할 수 없다. 병원처럼 지원하지 않는 원천은 거부한다.

## 재현 절차

Python 3.12와 requirements.txt 및 requirements_acquire.txt의 환경 및 Rust 금액 파서를 준비한다. 원자료는 공개하지 않는다. 기존 로컬 자료를 갖춘 경우 아래 명령은 모델 학습 없이 시설 감사 보고서 8개와 manifest를 새 출력 폴더에 저장한다. 원본 manifest/CSV 해시와 행 수를 전후 대조한다.

```powershell
python -B -X utf8 scripts/audit_facility_eligibility.py --project "E:/2026/Balance Compass Project" --output "검증 근거/시설자격_실측" --as-of 2026-11-27 --reference-start 2026-01-01
$env:OMP_NUM_THREADS='2'
$env:OPENBLAS_NUM_THREADS='2'
$env:MKL_NUM_THREADS='2'
python -B -X utf8 -m unittest discover -s tests -v
```

출력 폴더는 새 경로여야 한다. 실패 시 원문을 삭제·수정하거나 자격 플래그를 강제로 바꾸지 않는다. 원천을 독립적으로 정정·입증한 뒤 새 보고서를 만든다. 통합 기술 검사 145개가 통과했다. 이는 제어 입력을 포함한 구현 검사이며 실제 논문 성능·효과 크기·검정력을 측정한 실험은 아니다.

## 남은 연구 조건

정제 후 계약 2,857,449건 중 엄격 단지 연결은 385,030건(13.4746%), 3,159개 코드다. 현재 좌표·이름 일치는 독립 정답 라벨 정확도와 다르며 지역별 선택 편향이 남는다. 2025년 목표 금액 집계는 연결 편향 감사에서 이미 관찰했다. 이를 가설·모델 기준 조정에 쓰지 않았지만 테스트를 전혀 보지 않았다는 주장은 하지 않는다.

최종 특징·비교 실행 동결, 독립 연결 정답 검증, 시설 물리 ID/과거 운영·공표 이력, 실제 학습의 자원 검사와 완주 결과는 남아 있다. strict_asof는 당시 공표 빈티지 미확보로 막힌다. 확장 특징군 비교는 탐색적이다. 실제 학습은 stopped_by_user이고 8개 가설의 실측 결과는 미측정이다. 완성 원고나 게재 근거가 없어 논문 PDF를 만들지 않았다. 원문 데이터·모델·사적 검사 기록을 공개하지 않는다.
