# 10차 외부 특징·위치 연산 경계 검증

기준은 한영 안내가 보완된 공개9차 1c2d797이다. 실제 취득·학습은 실행하지 않고 제어 입력으로 누락된 경계를 재현했다. 8가설·15개 평가·기존 수식·시간 분할·과학 문턱은 유지한다.

## 재현과 수리

| 검증 경로 | 10차 수정 | 검증 범위 |
|---|---|---|
| 위치 계산 | 중복 인덱스를 내부 행 위치와 분리 | 원 인덱스·순서·단지별 값 보존 |
| 식별키 | 숫자/문자 혼합을 임의 변환하지 않고 거부 | 문자열 01과1은 구분, 미상 키는 결측 유지 |
| 특징 열 | 값/출처/결측 표시 열 모두 충돌 검사 | 기존 계약 열 덮어쓰기 거부 |
| 회귀·산술 | 178개 검사 및 독립 직선거리 산술 대조 | 실제 위치 정답·역사적 시설 운영 인증 아님 |

station_features에서 서로 다른 서울·부산 단지에 같은 행 인덱스7을 붙이면 기존 loc[7] 대입이 양쪽 행을 함께 갱신했다. 1km 내 물리역/노선 수의 정답[1,2]가[2,2]로 덮어써졌다. 내부 연산에 순차 위치 인덱스를 사용하고 반환 전에 원 인덱스를 복원했다. cluster_id와 원행 순서는 유지하고 원본 DataFrame을 변경하지 않는다. 좌표가 모두 결측인 조기 반환 경로도 원 인덱스를 보존한다. 조기 반환에서도 직선거리 설명·지구 반지름·역사적 가용성 미입증 메타데이터를 반환한다. 추가 검사에서 기존 누락을 KeyError1개로 재현한 뒤 설정 위치를 앞당겨 수리했다.

외부 관측 entity_key/source_id/record_id와 계약 source_row_id/결합키, 공간 입력 cluster_id/facility_id/line은 문자열 식별자여야 한다. 기존에는 관측의 숫자1과 문자열1이 by_key의 str 변환에서 같은 키가 되어 관측이 덮어써질 수 있었다. 노선 수 집계도 원형/문자열 변환의 차이로 환승 판정과 일치하지 않을 수 있었다. 이제 숫자·불리언 등 비문자 식별자를 ValueError로 거부한다. 공란/누락의 기존 규칙은 유지한다. 계약의 미상 결합키는 결측 특징으로 남길 수 있고, 원행ID·원천ID·시설/노선ID의 누락은 계속 거부한다. 숫자를 임의로 문자열화하거나 앞자리0을 복원하지 않는다. 표준 특징 CSV는 문자열을 보존해 읽으므로 정상 입력 방식은 유지된다.

join_features는 특징명 자체만 충돌 검사하고 특징명__record와 특징명__missing을 덮어쓸 수 있었다. 현재 관측에서 실제 생성하는 세 종류 열의 집합을 먼저 계산해 계약 표와 하나라도 겹치면 쓰기 전에 거부한다. 기존 값을 지우거나 이름을 자동 변경하지 않는다.

## 검증 근거와 수치

| 검사 | 수정 전 | 수정 후 |
|---|---|---|
| 새7개 회귀 method | 11개 하위 조건 실패 | 7개 통과 |
| 전체 통합 | 9차171개 | 10차178개, 조기 반환 수리 후 전체 재실행 |
| 직접 haversine 대조 | 별도 제어 산술 | 40개 단지·25개 물리역·30개 노선기록 |
| 최근접 거리 최대 절대차 | 기준: 직접 atan2 산술 | 1.924×10⁻⁹m 미만 |
| 거리/개수/환승 | 중복 원행 인덱스 포함 | 500m/1000m 역수·노선수·환승거리 모두 일치 |

산술 차이는 코드의 수치 일치 정도이며 실제 좌표 측량 오차나 위치 정확도가 아니다. 제어 좌표는 고정 시드20261127로 생성했다. 실제 위치·시설표를 정정하거나 실제 계약을 다시 학습한 결과가 아니다. 모든 검사는 원본 보존과 실제 stopped_by_user 기록 SHA 불변을 확인했다.

## 남아 있는 연구 한계

단지 식별자 미상31행, 독립 위치 정답, 시설·인구·임대차 자료의 계약 당시 공개 판본, 실제 대규모 자원·예측 성능은 여전히 미입증이다. 직선거리 계산은 보행거리나 전국 시설 완전성을 증명하지 않는다. 과거4,845,086행 전수 감사는8차 기록으로 보존하며10차에서 재실행했다고 주장하지 않는다. 원문/모델/운영 근거는 공개하지 않는다. [9차 기록](9차_결과대조.md), [가설·수식·인용](논문_가설과_수식.md), [전체 차이](전체차이.diff).
