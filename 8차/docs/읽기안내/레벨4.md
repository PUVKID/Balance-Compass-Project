### 식별과 의존 구조 확인

일반 시간 분할의 단지 중첩과 보정 지역 집중을 목표별로 집계했다. 단지 미상 31행과 100행 이상·5단지 미만 지역을 그대로 보고하며 기존 표본·군집 문턱은 바꾸지 않았다.

KAPT 주소와 지도는 같은 출처 체계다. 한국부동산원 표는 광고 건수 차이와 주택 종류를 재검토했지만 격리를 유지한다. 정답 라벨 없는 정확도를 만들지 않는다.

| 구현·자료 계약 | 검증 방법 | 남는 경계 |
|---|---|---|
| ID와 스키마 | 원문 SHA·논리 행 번호·시군구/번지/단지명 재계산 | 구형 9열의 값 일치가 없는 ID 칼럼을 복원하지 않음 |
| 실행기 | 선택 경로를 계획/상태에, SHA를 상태에 보존 | 명시 입력 누락 시 구형 입력으로 자동 대체하지 않음 |
| 완료 처리 | 일반·홀드아웃·통합 후 원래 입력/엔진 해시 대조 | 바뀐 산출물은 실패 근거로 남고 완료로 승인되지 않음 |
| 연결 품질 | 현재 지도와 동일 출처의 주소 연결 진단 | 독립 좌표 정답·전국 대표성·현장 거리 정확도 미입증 |
