# LEVEL 4 - Advanced

일반 시간 분할의 단지 중첩과 보정 지역 집중을 목표별로 집계했다. 단지 미상 31행과 100행 이상·5단지 미만 지역을 그대로 보고하며 기존 표본·군집 문턱은 바꾸지 않았다.

KAPT 주소와 지도는 같은 출처 체계다. 한국부동산원 표는 광고 건수 차이와 주택 종류를 재검토했지만 격리를 유지한다. 정답 라벨 없는 정확도를 만들지 않는다.
