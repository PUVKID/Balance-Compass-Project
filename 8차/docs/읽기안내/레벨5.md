### 추론 가능한 범위 확정하기

군집 누락이 있는 전체 테스트의 bootstrap 확정 판정은 기존 규칙상 불완전하다. 학습 단지 중첩이 큰 시간 평가를 미학습 단지 일반화로 바꾸어 부르지 않는다. 보정 100행은 교환가능성·독립성을 입증하지 않는다.

한국은행 공식 역사 문서 13건은 날짜·값의 부분 근거다. 당시 취득판의 무수정성·모든 금리 동결 회의·시설 역사·라벨 공개 시점을 입증하지 않는다. 8가설·15개 평가와 기존 수식·문턱, 확증·탐색 경계를 유지한다.

| 추론 조건 | 현재 관측 | 해석 제한 |
|---|---|---|
| 군집 완전성 | 적격 31행 미상, 최종 테스트 월세 1·전세 3행 | 전체 단지 bootstrap CI가 완비됐다고 확정할 수 없음 |
| 보정 의존성 | 100행 이상·5단지 미만 월세 20·전세 29지역 | 기존 문턱 유지, 100행은 독립성·교환가능성 보증 아님 |
| 일반화 | 테스트의 학습 단지 중첩을 목표별 진단 | 시간 평가와 미학습 단지·서울 홀드아웃 분모를 구분 |
| 역사·확증 | 8가설·15평가·기존 과학 조건 유지 | 부분 역사 근거와 사후 2025 집계 열람을 확증 승인으로 바꾸지 않음 |
