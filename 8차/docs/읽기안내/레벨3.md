### 감사 결과와 실행 중지 읽기

전수 감사는 원문·확장 표의 SHA와 21항목·source_row_id·cluster_id를 48개월 모든 행에서 대조하고 Rust 금액 파서로 기존 정제를 실행했다. 구형 9열 입력과도 모든 행의 값을 대조했다. 실행기는 --manifest로 확장 입력을 선택하고 계획·상태에 경로와 SHA를 남긴다. 모델 적합은 금지했다.

연구조건_동결.json의 입력·코드·감사 해시는 검사 시점 조건을 고정한다. features.json이나 학습 재개 승인이 아니다. 기존 사전 검사는 입력 기술 검사만 수행한다.

| 실행 단계 | 이번 확인·수리 | 실행 경계 |
|---|---|---|
| 계획 | --manifest로 확장 명세를 명시 | --execute 없는 계획은 학습·실행 폴더를 만들지 않음 |
| 일반·홀드아웃 | 같은 manifest 경로와 시작 SHA를 추적 | 각 실행 후 입력·엔진 변경을 거부 |
| 통합 분석 | 반환 후 manifest·엔진 SHA를 다시 대조 | 분석 중 바뀌면 failed·종료 2, completed 금지 |
| 재현 검사 | 기존 166개와 통합 후 변경 회귀 2개 | 제어 자료 검사이며 실제 성능·학습 재개가 아님 |
