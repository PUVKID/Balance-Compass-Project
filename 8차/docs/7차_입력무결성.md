# 7차 입력 무결성과 학습 없는 사전 검사

7차는 6차 이후의 입력 경계를 추가 검토해 재현된 오류를 고쳤다. 실제 학습·취득을 실행하지 않았고 모델 성능·가설 지지 결과를 만들지 않았다. 기존 8개 가설·15개 평가와 수식·인용은 유지한다.

| 범위 | 기존 위험 | 7차 처리 |
|---|---|---|
| CSV 입구 | 중복 머리글·빈 행·행 폭/NUL 오류를 일부 허용 | NUL/원문 구조를 먼저 검사하고 동일 바이트를 파싱 |
| 특징 값 | 유한한 숫자면 음수 개수·소수 시설도 통과 | 정의역·정수 개수·기존 단위 계약 검사 |
| 특징 manifest | feature/source 목록만으로 좁은 스키마 통과 | 전체 관측 칼럼·유효기간·공표시점·중복 ID 검사 |
| H5 재분석 | 직접 writer에서는 고정 버전·인자 비교 누락 | runner와 writer가 공통 설정 검증 사용 |
| 군집 근거 | 저장 예측 cluster 칼럼 누락을 암묵적 강등 | 필수 칼럼으로 검사; 값 미상은 불확실성 미산출 유지 |
| 분석 설정 | 소수 반복수·NaN 군집 수 등이 생성됨 | 개수·시드 타입과 범위 검사 |
| 확정 판정 | 변경된 과학 설정/부족한 재표집 근거를 확정으로 표시 가능 | 고정 조건·반복수·군집 수·유효 반복 근거 검사 |
| 사전 검사 | 외부 특징 기술 검증을 별도로 확인하기 어려움 | 모델 import/fit 없는 CLI와 새 파일 보고서 추가 |

## 표 구조와 동일 바이트

`input_contracts.strict_csv`는 중복/빈 머리글, 필수 칼럼, 논리 행별 열 수를 먼저 검사한다. 빈 행을 건너뛰거나 여분 칼럼을 행 인덱스로 삼는 자동 해석을 허용하지 않는다. NUL 문자는 파서 사이에서 ID/숫자 셀이 잘릴 수 있으므로 거부한다. 따옴표 안 쉼표·줄바꿈은 정상 CSV로 다룬다. 검사 후 동일 바이트를 pandas로 파싱하고 원행 ID·군집·지역·날짜 문자열과 앞자리 0을 보존한다. 구조 검사를 위해 원행 리스트 전체를 복제하지 않는다. 숫자 칼럼은 원래 수치 타입을 쓸 수 있다.

저장 예측 CSV는 source_row_id, cluster_id, region, date, actual_won, prediction_won을 요구한다. 빈 군집 값 자체는 과거와 같이 불확실성 부족으로 처리할 수 있지만, 칼럼을 빼서 서로 다른 군집 근거의 H5를 비교할 수는 없다. 각 목표/분할 건수와 고정 날짜·전체 서울 집합·출처 해시는 6차 조건을 유지한다.

## 특징 관측의 전체 계약

관측은 entity_key, feature, value, valid_from, valid_to, published_at, source_id, record_id를 모두 가져야 한다. manifest 검사와 실제 결합 모두 같은 validate_observations를 적용한다. required 날짜는 ISO YYYY-MM-DD, 유효기간은 [valid_from,valid_to), 빈 valid_to는 끝 미정이다. 공표시점에는 시간대가 필요하다. 동일 키/특징/시작일/공표시점 중복과 source_id/record_id 중복은 거부한다. manifest에서 읽은 실제 관측 바이트의 해시도 재확인한다.

| 특징 | 허용 조건 | 보존한 정상 사례 |
|---|---|---|
| 인구·세대·시설·거래·일수 개수 | 0 이상 정수; 단지 세대/동/최고층은 양수 | 거래·시설 수 0 |
| 거리·면적·주차/승강기 비율 | 0 이상 | 거리 0·주차 0 |
| 건폐율 / 용적률 | 기존 변수 사전의 % 단위; 0~100 / 0 이상 | 용적률 350% |
| 상대층 / 금리·변화율 | 상대층≤1; 금리·변화율은 유한 수치 | 지하 상대층·음수 금리·음수 YoY |
| 가격·가격지수 | 양수 | 실제 결측은 관측 없음으로 보존 |

단위는 위 표의 %·비율·개수 계약을 따른다. 기존 변수 설계의 단위를 변경하지 않았다. 임의의 이상치 상한·가격 문턱을 만들지 않았다. 값이 0인 개수와 값이 없는 관측은 구분한다. 시설·단지 원천의 자격 재계산·역사 미입증 소급 금지는 6차 조건을 유지한다. 값 정의역 검사만으로 좌표/연결 정답·전국 완전성을 인증하지 않는다.

## H5의 방법 비교

validate_holdout_settings는 일반 결과와 홀드아웃의 목표 집합, 라이브러리 버전, estimator_details/no_deposit_estimator_details의 parameters를 대조한다. REAL은 버전/주 추정기 설정 근거가 필요하다. 서로 다른 고정 인자의 실행을 지역 이동 효과 하나로 해석할 수 없다. 검증 자료에서 선택된 모델과 학습된 반복횟수는 결과이므로 강제로 같게 만들지 않는다. 합성 입력은 논문 지지로 쓰지 않는다.

## 확정 판정의 근거

기존 예측구간 alpha=.1, coverage_tolerance=.02, 가설 family confidence=.95, family_size=15, bootstrap 기본 B=9,999, minimum_clusters=20, minimum_group_n=30, minimum_group_clusters=5, regional_calibration_min=100, seed=20261126을 유지한다. prediction alpha=.1은 가설 가족 오류율 .05와 구분한다. 연구용 90% 예측구간과 bootstrap 추론의 수식·문턱을 변경하지 않았다.

`research_protocol`의 고정 조건과 다른 설정 또는 B<9,999는 기술 확인이다. 효과를 계산할 수 있더라도 partial/inconclusive로 남긴다. B를 늘리는 것은 허용하지만 화면의 요청 반복수는 해당 config와 같아야 한다. measured 행은 k≥20 및 ceil(.8×B)≤B_valid≤B의 근거를 갖춰야 한다. 이 80% 유효 반복 조건도 기존 연구 계산의 규칙을 화면에 적용한 것이다. H6는 low/high 각각 최소20단지와 전체 군집 이하의 근거가 필요하며, 두 하위집단 군집 수 합은 전체 계약 수를 넘을 수 없다. H3는 CI가 (-.02,.02)에 완전히 들어가면 support, CI가 그 범위 밖으로 분리되면 not_support, 그 외 inconclusive다. 다른 방향 가설은 CI 하한>0이면 support, 상한≤0이면 not_support다. 합성은 확정 지지를 억제한다.

군집 percentile CI가 점추정치를 포함해야 한다고 강제하지 않는다. 군집/지역 의존·시간 이동·학습 불확실성의 한계와 근사 추론이라는 해석도 그대로다. [기존 수식·출처](논문_가설과_수식.md), [탐색적 확장식](확장분석_수식과해석.md). 새 논문·검증된 신규 통계량·추가 가설을 주장하지 않는다.

## 학습 없는 사전 검사

```powershell
python -B -X utf8 -m rentlab.feature_preflight --features features.json --output new_preflight.json
python -B -X utf8 -m rentlab.feature_preflight --output missing_input.json
```

출력 경로는 새 파일이어야 하고 부모 폴더는 있어야 한다. 기존 파일을 덮어쓰지 않는다. feature_preflight는 sklearn/engine을 import하지 않고 모델을 fit하지 않는다. 유효 특징 입력은 status=validated_input_only/종료0, 미제공은 missing_input/종료2, 잘못된 입력은 invalid_input/종료2다. 원천 CSV의 손상 인용·NUL·지원하지 않는 인코딩도 invalid_input JSON에 기록한다. 보고서 저장 실패도 종료2이며 메시지로 구분한다. 사전 검사 통과는 학습 실행 승인이나 연구 전체 준비 완료가 아니다.

보고서에는 manifest/관측/검증 코드 해시, 전체 관측 행 수, 특징별 행 수·서로 다른 entity 수·원천 수·값 범위·유효 시작일 범위·끝 미정 행 수와 오류를 남긴다. 이 값들은 특징 관측 표의 분모이며 계약 수나 예측 성능이 아니다. experiment_readiness=not_evaluated, training_started=false, 과거 이용가능성과 원천 완전성은 미입증으로 남긴다. 계약별 조인·시기별 결측·독립 연결 정답·자원 사용·과거 공표 이력은 별도 검사다.

현재 승인할 특징 manifest는 제공되지 않은 상태로 사전 검사를 실행했고 missing_input/종료2를 확인했다. 기술 테스트의 최소 정상 fixture 통과와 실제 준비 상태를 섞지 않는다. 실제 수집·학습 JSON은 변경하지 않았다.

## 검증과 남은 조건

새 실패 제어를 실제로 확인한 뒤 수리했고, 통합161개 검사(25.416초), Node app.js 구문 검사가 통과했다. 여기에는 기존 제어 fixture를 과학 조건에 맞춘 회귀 검사가 포함된다. 실제 모델 학습과 논문 결과는 미측정이다. 계약 2,857,449건 중 단지 연결 385,030건이라는 앞 감사의 분모·선택 편향을 유지하며 전체 연결 정답 정확도로 확대하지 않는다. 2025년 목표 집계 열람 이력도 숨기지 않는다.

시설의 독립 물리 식별/과거 운영·공표 이력, 독립 단지 연결 정답, 최종 특징·비교 실행 동결, 실제 학습 자원 검사와 완주 결과는 남아 있다. 원자료를 임의 수정해 이 조건을 채우지 않는다. 사용자 학습 중지 상태를 유지한다. 완성 원고·게재 근거가 없어 논문 PDF를 만들지 않았고 코드·방법 설명만 공개한다.
