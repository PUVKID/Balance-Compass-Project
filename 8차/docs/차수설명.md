## LEVEL 1 - Beginner

### 원문과 결과를 구분하기

영수증 상자에 빠진 종이나 바뀐 숫자가 없는지 전부 비교했다. 하지만 같은 주소라고 같은 단지인지, 예전에 그 시설이 있었는지는 영수증 개수만으로 알 수 없다.

단지를 알 수 없는 계약 31건에 각각 다른 단지 번호를 만들지 않았다. 100건이 한 단지에 몰렸다면 100개의 독립 사례처럼 설명하지 않는다.

| 먼저 볼 것 | 쉬운 설명 | 기억할 점 |
|---|---|---|
| 원문 대조 | 받은 영수증과 정리한 표의 모든 값을 비교 | 숫자가 같아도 과거 공개판까지 증명되지는 않음 |
| 같은 단지 | 같은 단지의 계약은 서로 관련될 수 있음 | 100계약을 100개 독립 사례로 세지 않음 |
| 모르는 단지 | 단지 미상 31행은 그대로 보존 | 가짜 번호로 독립 사례를 만들지 않음 |
| 현재 결과 | 자료 검사와 실행기 수리를 완료 | 실제 학습은 중지 상태, 예측 성능은 미측정 |

## LEVEL 2 - Explorer

### 분모와 연결을 따라가기

원문 4,845,086행 → 기존 규칙의 적격 2,857,449행 → 현재 단지 연결 385,030행으로 분모가 줄어든다. 외부 표 14개 427,418행은 중복 판본을 포함하며 계약 수가 아니다.

학교 설립일·공원 고시일·역 기준일과 과거 운영·공표 이력은 서로 다르다. 확보 상태와 사용 승인을 분리했다.

| 자료 흐름 | 확인한 연결 | 분모·출처의 차이 |
|---|---|---|
| 원문 → 확장 표 | 48개월의 21항목과 원행·단지 ID 대조 | 원문 4,845,086행 |
| 정제 → 단지 연결 | 기존 포함 규칙과 현재 KAPT 지도 확인 | 적격 2,857,449행 중 연결 385,030행 |
| 외부 표 → 후보 | 14개 표의 구조·행수·해시 확인 | 427,418행은 중복 판본을 포함하며 계약 수가 아님 |
| 역사 문서 → 조건 | 금리 날짜·값 13건의 공식 근거 | 일부 금리 근거와 모든 특징의 과거판 승인은 다름 |

## LEVEL 3 - Practitioner

### 감사 결과와 실행 중지 읽기

전수 감사는 원문·확장 표의 SHA와 21항목·source_row_id·cluster_id를 48개월 모든 행에서 대조하고 Rust 금액 파서로 기존 정제를 실행했다. 구형 9열 입력과도 모든 행의 값을 대조했다. 실행기는 --manifest로 확장 입력을 선택하고 계획·상태에 경로와 SHA를 남긴다. 모델 적합은 금지했다.

연구조건_동결.json의 입력·코드·감사 해시는 검사 시점 조건을 고정한다. features.json이나 학습 재개 승인이 아니다. 기존 사전 검사는 입력 기술 검사만 수행한다.

| 실행 단계 | 이번 확인·수리 | 실행 경계 |
|---|---|---|
| 계획 | --manifest로 확장 명세를 명시 | --execute 없는 계획은 학습·실행 폴더를 만들지 않음 |
| 일반·홀드아웃 | 같은 manifest 경로와 시작 SHA를 추적 | 각 실행 후 입력·엔진 변경을 거부 |
| 통합 분석 | 반환 후 manifest·엔진 SHA를 다시 대조 | 분석 중 바뀌면 failed·종료 2, completed 금지 |
| 재현 검사 | 기존 166개와 통합 후 변경 회귀 2개 | 제어 자료 검사이며 실제 성능·학습 재개가 아님 |

## LEVEL 4 - Advanced

### 식별과 의존 구조 확인

일반 시간 분할의 단지 중첩과 보정 지역 집중을 목표별로 집계했다. 단지 미상 31행과 100행 이상·5단지 미만 지역을 그대로 보고하며 기존 표본·군집 문턱은 바꾸지 않았다.

KAPT 주소와 지도는 같은 출처 체계다. 한국부동산원 표는 광고 건수 차이와 주택 종류를 재검토했지만 격리를 유지한다. 정답 라벨 없는 정확도를 만들지 않는다.

| 구현·자료 계약 | 검증 방법 | 남는 경계 |
|---|---|---|
| ID와 스키마 | 원문 SHA·논리 행 번호·시군구/번지/단지명 재계산 | 구형 9열의 값 일치가 없는 ID 칼럼을 복원하지 않음 |
| 실행기 | 선택 경로를 계획/상태에, SHA를 상태에 보존 | 명시 입력 누락 시 구형 입력으로 자동 대체하지 않음 |
| 완료 처리 | 일반·홀드아웃·통합 후 원래 입력/엔진 해시 대조 | 바뀐 산출물은 실패 근거로 남고 완료로 승인되지 않음 |
| 연결 품질 | 현재 지도와 동일 출처의 주소 연결 진단 | 독립 좌표 정답·전국 대표성·현장 거리 정확도 미입증 |

## LEVEL 5 - Expert

### 추론 가능한 범위 확정하기

군집 누락이 있는 전체 테스트의 bootstrap 확정 판정은 기존 규칙상 불완전하다. 학습 단지 중첩이 큰 시간 평가를 미학습 단지 일반화로 바꾸어 부르지 않는다. 보정 100행은 교환가능성·독립성을 입증하지 않는다.

한국은행 공식 역사 문서 13건은 날짜·값의 부분 근거다. 당시 취득판의 무수정성·모든 금리 동결 회의·시설 역사·라벨 공개 시점을 입증하지 않는다. 8가설·15개 평가와 기존 수식·문턱, 확증·탐색 경계를 유지한다.

| 추론 조건 | 현재 관측 | 해석 제한 |
|---|---|---|
| 군집 완전성 | 적격 31행 미상, 최종 테스트 월세 1·전세 3행 | 전체 단지 bootstrap CI가 완비됐다고 확정할 수 없음 |
| 보정 의존성 | 100행 이상·5단지 미만 월세 20·전세 29지역 | 기존 문턱 유지, 100행은 독립성·교환가능성 보증 아님 |
| 일반화 | 테스트의 학습 단지 중첩을 목표별 진단 | 시간 평가와 미학습 단지·서울 홀드아웃 분모를 구분 |
| 역사·확증 | 8가설·15평가·기존 과학 조건 유지 | 부분 역사 근거와 사후 2025 집계 열람을 확증 승인으로 바꾸지 않음 |

## 공통 수치·분할·감사 근거

8차 원자료 감사의 전체 수치입니다. **최초 코드 검사 166개**와 이후 추가한 **통합 완료 경계 회귀 2개**를 구분합니다. 자료·분할·미상 행은 변경하지 않았습니다.

| 검증 대상 | 직접 확인 | 해석 |
|---|---|---|
| 48개월 원문→확장 입력 | 4,845,086행·21항목/원행ID/군집ID 전수 일치 | 다운로드한 원문과 일치; 당시 신고판 입증 아님 |
| 기존 정제 | 2,857,449행; 비신규 1,964,806 / 건축연도 오류 22,831 제외 | 배제 기준 변경 없음 |
| 외부 표 | 14개 CSV·427,418행; 행수/해시/행 폭 일치 | 원응답 전체 재검사와 구별 |
| 현재 단지 연결 | 385,030/2,857,449 = 13.4746% | 위치 정답 정확도·전국 대표성 아님 |
| 군집 미상 | 적격 31행; 최종 테스트 월세1/전세3행 | 행 유지; 군집 추론의 부족 근거를 숨기지 않음 |
| 보정 집중 | 100행 이상이면서 5단지 미만: 월세 20 / 전세 29지역 | 100행은 100독립단지와 다름 |
