잔차 순위 ceil((m+1)×0.90)의 split conformal을 쓴다. 단지 군집 percentile bootstrap 9,999회와 15개 평가 Bonferroni 원칙을 적용한 근사 구간을 계산한다. 시간 이동에서 90% 포함률이나 정확한 가족 95% 보장을 주장하지 않는다. 모델 재학습 불확실성은 포함하지 않는다.
