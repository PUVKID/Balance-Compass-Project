## 최신 6차

기존 15개 목표별 family, alpha=.1, bootstrap=9,999와 고정 서울 H5를 유지한다. full Seoul ID 집합 및 paired 정답·날짜·지역·군집을 검사해 사후 부분표본 비교를 막는다. Σn_g=n 및 Σn_g MAE_g/n=MAE, RMSE≥MAE가 표시 정합 조건이다.

신뢰구간은 학습된 모델 조건부 군집 bootstrap 근사이며 시간 이동·군집 의존·작은 표본에서 보장을 주장하지 않는다. 시설 보고서는 진실성·완전성 검증을 대신하지 않으며 역사를 입증하지 못한다. 새 가설·효과 문턱·통계량·문헌 인용을 추가하지 않았다. 기존 수식과 인용 원문은 연결 문서에 보존했다.

| 변경 | 확인 | 제한 |
|---|---|---|
| 저장 결과·화면 | 원행·분할·모드·서울 집합·수치 정합 | 실측 결과 미측정 |
| 시설 원천 | 4종 원문을 두 기준일로 검사 | 과거 운영·전국 완전성 미입증 |
| 기술 검증 | 145개 검사 통과 | 실제 학습 중지 |

## 최신 7차

H1–H8와15가족, 예측 alpha=.1/가설 family confidence=.95, seed20261126 및 최소 군집/지역 조건을 보존한다. B≥9999, ceil(.8B)≤B_valid≤B, k≥20은 확정 상태의 필수 근거다. 설정이 달라지면 효과가 있어도 기술 partial/inconclusive다.

H5는 같은 스냅숏·전체 서울 계약과 고정 라이브러리/추정기 인자를 비교한다. 선택된 모델·학습 반복수는 결과라 달라질 수 있다. CI가 estimate를 포함한다는 조건은 넣지 않았고 군집 percentile 근사의 한계를 유지한다. 새 유의성·가설·모델 성능을 주장하지 않는다.

| 확인 | 이번 관측 | 남은 조건 |
|---|---|---|
| 기술 검사 | 161개 통과 | 실측 성능 미측정 |
| 사전 검사 | 정상/미제공/부적합/덮어쓰기 거부 제어 통과 | 계약 조인·실험 전체 readiness 별도 |
| 실제 입력 | 특징 미제공 missing_input 확인 | 최종 특징 동결 미완료 |
| 실행 상태 | 학습 중지 유지 | 역사·물리정답·자원 검증 별도 |
