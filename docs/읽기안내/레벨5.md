## 6차 기록

기존 15개 목표별 family, alpha=.1, bootstrap=9,999와 고정 서울 H5를 유지한다. full Seoul ID 집합 및 paired 정답·날짜·지역·군집을 검사해 사후 부분표본 비교를 막는다. Σn_g=n 및 Σn_g MAE_g/n=MAE, RMSE≥MAE가 표시 정합 조건이다.

신뢰구간은 학습된 모델 조건부 군집 bootstrap 근사이며 시간 이동·군집 의존·작은 표본에서 보장을 주장하지 않는다. 시설 보고서는 진실성·완전성 검증을 대신하지 않으며 역사를 입증하지 못한다. 새 가설·효과 문턱·통계량·문헌 인용을 추가하지 않았다. 기존 수식과 인용 원문은 연결 문서에 보존했다.

| 변경 | 확인 | 제한 |
|---|---|---|
| 저장 결과·화면 | 원행·분할·모드·서울 집합·수치 정합 | 실측 결과 미측정 |
| 시설 원천 | 4종 원문을 두 기준일로 검사 | 과거 운영·전국 완전성 미입증 |
| 기술 검증 | 145개 검사 통과 | 실제 학습 중지 |

## 7차 기록

H1–H8와15가족, 예측 alpha=.1/가설 family confidence=.95, seed20261126 및 최소 군집/지역 조건을 보존한다. B≥9999, ceil(.8B)≤B_valid≤B, k≥20은 확정 상태의 필수 근거다. 설정이 달라지면 효과가 있어도 기술 partial/inconclusive다.

H5는 같은 스냅숏·전체 서울 계약과 고정 라이브러리/추정기 인자를 비교한다. 선택된 모델·학습 반복수는 결과라 달라질 수 있다. CI가 estimate를 포함한다는 조건은 넣지 않았고 군집 percentile 근사의 한계를 유지한다. 새 유의성·가설·모델 성능을 주장하지 않는다.

| 확인 | 이번 관측 | 남은 조건 |
|---|---|---|
| 기술 검사 | 161개 통과 | 실측 성능 미측정 |
| 사전 검사 | 정상/미제공/부적합/덮어쓰기 거부 제어 통과 | 계약 조인·실험 전체 readiness 별도 |
| 실제 입력 | 특징 미제공 missing_input 확인 | 최종 특징 동결 미완료 |
| 실행 상태 | 학습 중지 유지 | 역사·물리정답·자원 검증 별도 |

## 8차 기록

군집 누락이 있는 전체 테스트의 bootstrap 확정 판정은 기존 규칙상 불완전하다. 학습 단지 중첩이 큰 시간 평가를 미학습 단지 일반화로 바꾸어 부르지 않는다. 보정 100행은 교환가능성·독립성을 입증하지 않는다.

한국은행 공식 역사 문서 13건은 날짜·값의 부분 근거다. 당시 취득판의 무수정성·모든 금리 동결 회의·시설 역사·라벨 공개 시점을 입증하지 않는다. 8가설·15개 평가와 기존 수식·문턱, 확증·탐색 경계를 유지한다.

| 검증 대상 | 직접 확인 | 해석 |
|---|---|---|
| 48개월 원문→확장 입력 | 4,845,086행·21항목/원행ID/군집ID 전수 일치 | 다운로드한 원문과 일치; 당시 신고판 입증 아님 |
| 기존 정제 | 2,857,449행; 비신규1,964,806/건축연도오류22,831 제외 | 배제 기준 변경 없음 |
| 외부 표 | 14개 CSV·427,418행; 행수/해시/행 폭 일치 | 원응답 전체 재검사와 구별 |
| 현재 단지 연결 | 385,030/2,857,449 = 13.4746% | 위치 정답 정확도·전국 대표성 아님 |
| 군집 미상 | 적격31행; 최종 테스트 월세1/전세3행 | 행 유지; 군집 추론의 부족 근거를 숨기지 않음 |

## 9차 기록

같은 원천 manifest·설정이라는 선언만으로 결과 보정 행의 동일성을 대신하지 않는다. 이 수리는 H5 비교 입력의 추적성을 강화하지만 단지 간 독립성·시간 교환가능성·인과 일반화를 증명하지 않는다. 기존 8가설·15개 평가 및 다중평가 구간 조건은 유지하며 미입증 역사판과 군집 결손은 그대로 보고한다.

| 연구 조건 | 9차가 확인하는 범위 | 입증하지 않는 범위 |
|---|---|---|
| H5 비교 입력 | 서울 제외 보정 모집합과 관측 키 동일성 | 지역 이동의 인과적 효과 |
| 분석 추적성 | 반환 요약·저장 JSON·복사 해시 연결 | 역사판과 원천 자료의 사실성 |
| 불확실성 | 기존 단지 bootstrap·15평가 규칙 유지 | 시간/군집 독립성과 포함률 보장 |
| 실측 주장 | 제어 검사만171개 통과 | 실제 성능·가설 지지·논문 완료 |
