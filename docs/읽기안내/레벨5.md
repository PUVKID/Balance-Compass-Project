잔차 순위 ceil((m+1)×0.90)의 split conformal을 쓴다. 단지 군집 percentile bootstrap 9,999회와 15평가 Bonferroni 원칙을 적용한 근사 구간을 계산한다. 시간 이동에서 90% 포함률이나 정확한 가족 95% 보장을 주장하지 않는다. 모델 재학습 불확실성은 포함하지 않는다.

| 재현 요소 | 기록 | 경계 |
|---|---|---|
| 자료 | 원본 SHA·스냅숏·요청 조건 | 역사적 지역·모집단 완전성 미검증 |
| 모델 | 버전·설정·분할·후보 예측 | 고정 CPU 설정, 대규모 완료 성능 없음 |
| 가설 | 효과·구간·n·군집·유효 반복·코드 SHA | 표본 부족은 partial/unmeasured |
| 제안 지표 | BC_loss·3개 가중치 민감도 | 검증 전 조합 지표, 모델 선택에 미사용 |
