**전국 실측 본실험은 미실행이다.** 아래 구현과 합성 검증을 실측 성능으로 해석하지 않는다.

<a id="reading-level-5"></a>






보정 표본 n과 alpha=0.1에 대해 `ceil((n+1)*(1-alpha))` 순위의 절대 잔차를 선택한다. 순위가 n을 넘으면 구간을 산출하지 않고 null로 남긴다. 유한표본 포함률 보장은 교환가능성 등의 가정에 의존하며 시간·지역 이동 환경에 무조건 적용할 수 없다. 테스트에는 MAE, RMSE, 구간 포함률, 평균 폭, interval score와 표본 수를 저장한다. 원비율은 보존하며 UI 백분율만 소수 첫째 자리로 반올림한다.

| 재현 요소 | 기록·동작 | 미완료 범위 |
|---|---|---|
| 입력 | 원본 SHA-256·출처·시각·스냅숏 | 전국 완결성 공식 코드 대조 |
| 금액 | i64 원 단위, Rust 바이너리 해시 | 속도 향상 전후 실측 없음 |
| 모델 | CPU, 부스팅 random_state=42 | 불확실성 반복실험·하이퍼파라미터 탐색 |
| 평가 | train-only 전처리·고정 시간·지역 홀드아웃 | 단지 군집 부트스트랩 |
| 민감도 | 미측정 상태를 결과 목록에 보존 | 신고 지연·갱신·지역 conformal·분위수 비교 |
| 출력 | 기존 폴더 보호·임시 폴더 완성 후 이름 변경 | 대규모 전국 입력의 메모리·시간 실측 |

공개 자료는 임차가구 모집단 전체가 아니다. 지역명은 행정구역 코드의 역사적 동등성을 보장하지 않는다. 금액의 정확한 정수 정규화 이후 회귀·평가에는 부동소수 계산을 사용한다. 실제 데이터·모델·내부 출처·개인정보·인증자료는 이 저장소에 넣지 않는다. 나눔고딕은 [OFL](../../2차/web/OFL.txt)을 동봉했다. 현재 구현 상태와 남은 연구를 함께 해석하고, 합성 검사 성능을 실측 연구 성과로 인용하지 않는다. 구현 원문은 [엔진](../../2차/rentlab/engine.py), 입력·실행 계약은 [사용 안내](../../2차/사용안내.md)에서 확인한다.
