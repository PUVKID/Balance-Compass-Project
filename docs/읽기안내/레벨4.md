## 최신 6차

research_metrics의 저장 결과 입구와 내부 evaluate_frames 계산을 구분했다. 시설 자격은 facility_quality에서 행 단위로 만들고 feature_store가 해시 검증 후 보고서 전체를 재계산한다. spatial_features는 신뢰된 물리 ID의 거리 수학만 담당한다.

run_dashboard는 저장 summary의 지표·지역·가설 조합을 읽을 때 검증한다. rel_tol=1e-9/abs_tol=1e-6은 표시 집계의 부동소수점 비교만 허용한다. percentile CI와 점추정치의 포함 관계를 강제하지 않는다. 서버는 루프백 읽기 전용이며 학습 제어 기능이 없다.

| 변경 | 확인 | 제한 |
|---|---|---|
| 저장 결과·화면 | 원행·분할·모드·서울 집합·수치 정합 | 실측 결과 미측정 |
| 시설 원천 | 4종 원문을 두 기준일로 검사 | 과거 운영·전국 완전성 미입증 |
| 기술 검증 | 145개 검사 통과 | 실제 학습 중지 |

## 최신 7차

input_contracts의 strict_csv는 논리 행 구조를 먼저 확인한 뒤 동일 바이트를 읽는다. 원행 리스트 전체를 복제하지 않고 ID 앞자리0을 보존한다. feature_store는 manifest와 join 양쪽에서 validate_observations를 공유하고, experiment_runner와 research_metrics는 holdout 고정 설정 검증을 공유한다.

research_protocol은 기존 고정 과학 조건을 판정하며 변경 설정을 기술 partial로 남긴다. run_dashboard는 measured 표시 전에 config·요청/유효 bootstrap·군집 근거를 확인한다. feature_preflight는 검사 보고서만 저장하고 모델 실행 모듈과 분리했다.

| 확인 | 이번 관측 | 남은 조건 |
|---|---|---|
| 기술 검사 | 161개 통과 | 실측 성능 미측정 |
| 사전 검사 | 정상/미제공/부적합/덮어쓰기 거부 제어 통과 | 계약 조인·실험 전체 readiness 별도 |
| 실제 입력 | 특징 미제공 missing_input 확인 | 최종 특징 동결 미완료 |
| 실행 상태 | 학습 중지 유지 | 역사·물리정답·자원 검증 별도 |

## 최신 8차

일반 시간 분할의 단지 중첩과 보정 지역 집중을 목표별로 집계했다. 단지 미상 31행과 100행 이상·5단지 미만 지역을 그대로 보고하며 기존 표본·군집 문턱은 바꾸지 않았다.

KAPT 주소와 지도는 같은 출처 체계다. 한국부동산원 표는 광고 건수 차이와 주택 종류를 재검토했지만 격리를 유지한다. 정답 라벨 없는 정확도를 만들지 않는다.

| 검증 대상 | 직접 확인 | 해석 |
|---|---|---|
| 48개월 원문→확장 입력 | 4,845,086행·21항목/원행ID/군집ID 전수 일치 | 다운로드한 원문과 일치; 당시 신고판 입증 아님 |
| 기존 정제 | 2,857,449행; 비신규1,964,806/건축연도오류22,831 제외 | 배제 기준 변경 없음 |
| 외부 표 | 14개 CSV·427,418행; 행수/해시/행 폭 일치 | 원응답 전체 재검사와 구별 |
| 현재 단지 연결 | 385,030/2,857,449 = 13.4746% | 위치 정답 정확도·전국 대표성 아님 |
| 군집 미상 | 적격31행; 최종 테스트 월세1/전세3행 | 행 유지; 군집 추론의 부족 근거를 숨기지 않음 |
| 보정 집중 | 100행 이상이면서5단지 미만: 월세20/전세29지역 | 100행은100독립단지와 다름 |
| 금리 역사 문서 | 초기값+변경12건의 공식 문서13건 대조 | 발표일/값 근거; 모든 통계의 과거판 승인 아님 |
| 실행 입력 선택 | --manifest 경로·SHA 추적/166개 검사 통과 | 실제 학습·원자료 변경 없음 |
| 실제 학습 | stopped_by_user 원문 동일 | 성능/가설지지 미산출 |
