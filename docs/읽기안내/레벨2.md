# LEVEL 2 - Explorer

다른 수준: [LEVEL 1](레벨1.md) · [LEVEL 3](레벨3.md) · [LEVEL 4](레벨4.md) · [LEVEL 5](레벨5.md)

**전국 실측 본실험은 미실행이다.** 아래 구현과 합성 검증을 실측 성능으로 해석하지 않는다.

<a id="reading-level-2"></a>






입력은 국토교통부 공개 CSV와 파일별 manifest다. manifest에는 파일 이름뿐 아니라 SHA-256, 행 수, 취득 시각, 출처와 스냅숏 식별자가 들어간다. 해시는 프로그램이 읽는 파일과 기록한 파일이 같은지 검사한다. 그 내용이 실제 모집단을 완전히 대표한다는 뜻은 아니다.

| 단계 | 입력 | 출력 |
|---|---|---|
| 자료 검사 | 원본 CSV·manifest | 해시·행 수·중복 범위 검사 |
| 정제 | 금액·날짜·계약구분 | 분석 행과 제외 사유 |
| 비교 학습 | 2022–2023 계약 | 중앙값·지역 중앙값·Ridge·트리 부스팅 |
| 선택·보정 | 2024 상반기·하반기 | 선택 모델과 보정 반경 |
| 최종 평가 | 2025 계약 | 오차·구간·지역 집계·표·그림 |

학습에 쓰는 기간, 모델을 고르는 기간, 예측구간을 보정하는 기간, 마지막 평가 기간을 나눈다. 나중에 나온 답을 미리 학습에 넣는 일을 줄이기 위해서다. 실제 자료가 없을 때 `smoke` 명령으로 기술 흐름을 확인할 수 있지만 결과에는 SYNTHETIC이 표시된다. 현재 목록은 35 분석 목적이며 계산 가능한 30종과 구현·입력이 부족한 5종을 구분한다. CSV와 PNG가 한 쌍이면 한 분석이다. 상세 실행은 [사용 안내](../../2차/사용안내.md), 연구 목적은 [연구설계](../../2차/docs/연구설계.md)를 따른다.
