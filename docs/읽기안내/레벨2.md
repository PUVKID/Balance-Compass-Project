## 최신 6차

저장 예측 → ID·분할·모드 확인 → 같은 서울 계약 비교 → 가설 수치 → 화면 정합 확인 순서로 처리한다. 시설은 원문 행 → 중복·날짜·좌표 검사 → 재계산 가능한 보고서 → 특징 manifest로 이어진다.

한 행에 여러 보류 사유가 붙어도 원문 한 행은 그대로 보존된다. 일부 공원이 통과했다고 전국 공원 목록이 완전하다고 말할 수 없다. 현재 학교 목록이 통과해도 과거 학교 위치를 알게 된 것은 아니다.

| 변경 | 확인 | 제한 |
|---|---|---|
| 저장 결과·화면 | 원행·분할·모드·서울 집합·수치 정합 | 실측 결과 미측정 |
| 시설 원천 | 4종 원문을 두 기준일로 검사 | 과거 운영·전국 완전성 미입증 |
| 기술 검증 | 145개 검사 통과 | 실제 학습 중지 |

## 최신 7차

원문 CSV 구조 → ID와 수치 → 특징 관측의 기간/원천 → 같은 조건의 서울 비교 → 가설 효과·구간 → 화면 근거 검사로 연결된다. 파일 행 수, 특징 관측 수, 계약 수와 단지 군집 수는 서로 다른 분모다.

변화율과 금리는 음수가 정상일 수 있고 지하층 비율도 음수다. 이 값은 보존하면서 거리·인구·시설 개수의 불가능한 값을 거부한다. 현재 자료 통과와 과거 이용가능성은 같은 뜻이 아니다.

| 확인 | 이번 관측 | 남은 조건 |
|---|---|---|
| 기술 검사 | 161개 통과 | 실측 성능 미측정 |
| 사전 검사 | 정상/미제공/부적합/덮어쓰기 거부 제어 통과 | 계약 조인·실험 전체 readiness 별도 |
| 실제 입력 | 특징 미제공 missing_input 확인 | 최종 특징 동결 미완료 |
| 실행 상태 | 학습 중지 유지 | 역사·물리정답·자원 검증 별도 |
