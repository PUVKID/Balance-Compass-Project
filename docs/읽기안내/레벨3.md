| 명령 | 동작 | 보호 조건 |
|---|---|---|
| `python -m rentlab validate --manifest 경로` | 입력 검사 | 해시·행 수·칼럼·금액·월 형식 |
| `python -m rentlab smoke --output 새폴더` | 합성 기술 검사 | 실측 성과로 판정하지 않음 |
| `python -m rentlab.experiment_runner --root 자료 --run-dir 새폴더 --with-holdout 서울특별시` | 두 실행의 계획 | execute 없으면 무쓰기 |
| `python run_dashboard.py --result 결과폴더` | 읽기 전용 조회 | 엄격 summary·파일 허용 목록 |

## 최신 6차

Python 3.12, 고정 의존성, Rust 금액 파서를 준비하고 아래 검증 계약의 명령을 실행한다. 새 출력 폴더에만 시설 감사 manifest와 8개 보고서를 만든다. unittest discover는 제어 입력 145개를 검사한다. 실제 학습 명령은 실행하지 않는다.

hypothesis_results.json의 mode, input_files, hypotheses, artifacts를 확인한다. quality_reports에는 원천 ID·보고서 경로·해시를 넣어야 한다. ID/건수 오류는 예측 파일과 summary를 함께 확인하고, 시설 오류는 원문을 임의 평균하지 말고 독립 정정 근거를 확보한다.

| 변경 | 확인 | 제한 |
|---|---|---|
| 저장 결과·화면 | 원행·분할·모드·서울 집합·수치 정합 | 실측 결과 미측정 |
| 시설 원천 | 4종 원문을 두 기준일로 검사 | 과거 운영·전국 완전성 미입증 |
| 기술 검증 | 145개 검사 통과 | 실제 학습 중지 |

## 최신 7차

Python3.12와 고정 requirements.txt/requirements_acquire.txt 환경에서 python -B -X utf8 -m rentlab.feature_preflight --features features.json --output new_preflight.json을 실행한다. 기존 파일은 덮어쓰지 않고 sklearn/engine을 불러오거나 학습하지 않는다.

종료0은 validated_input_only, 종료2는 미제공/부적합 입력 또는 보고서 저장 실패다. JSON의 status·errors·manifest/관측/코드 SHA와 특징별 분모를 확인한다. 학습 재개 명령으로 해석하지 않는다. 실제 특징 미제공 검사도 종료2였으며 논문 실측은 없다.

| 확인 | 이번 관측 | 남은 조건 |
|---|---|---|
| 기술 검사 | 161개 통과 | 실측 성능 미측정 |
| 사전 검사 | 정상/미제공/부적합/덮어쓰기 거부 제어 통과 | 계약 조인·실험 전체 readiness 별도 |
| 실제 입력 | 특징 미제공 missing_input 확인 | 최종 특징 동결 미완료 |
| 실행 상태 | 학습 중지 유지 | 역사·물리정답·자원 검증 별도 |

## 최신 8차

전수 감사는 원문·확장 표의 SHA와 21항목·source_row_id·cluster_id를 48개월 모든 행에서 대조하고 Rust 금액 파서로 기존 정제를 실행했다. 구형 9열 입력과도 모든 행의 값을 대조했다. 실행기는 --manifest로 확장 입력을 선택하고 계획·상태에 경로와 SHA를 남긴다. 모델 적합은 금지했다.

연구조건_동결.json의 입력·코드·감사 해시는 검사 시점 조건을 고정한다. features.json이나 학습 재개 승인이 아니다. 기존 사전 검사는 입력 기술 검사만 수행한다.

| 검증 대상 | 직접 확인 | 해석 |
|---|---|---|
| 48개월 원문→확장 입력 | 4,845,086행·21항목/원행ID/군집ID 전수 일치 | 다운로드한 원문과 일치; 당시 신고판 입증 아님 |
| 기존 정제 | 2,857,449행; 비신규1,964,806/건축연도오류22,831 제외 | 배제 기준 변경 없음 |
| 외부 표 | 14개 CSV·427,418행; 행수/해시/행 폭 일치 | 원응답 전체 재검사와 구별 |
| 현재 단지 연결 | 385,030/2,857,449 = 13.4746% | 위치 정답 정확도·전국 대표성 아님 |
| 군집 미상 | 적격31행; 최종 테스트 월세1/전세3행 | 행 유지; 군집 추론의 부족 근거를 숨기지 않음 |
| 보정 집중 | 100행 이상이면서5단지 미만: 월세20/전세29지역 | 100행은100독립단지와 다름 |
| 금리 역사 문서 | 초기값+변경12건의 공식 문서13건 대조 | 발표일/값 근거; 모든 통계의 과거판 승인 아님 |
| 실행 입력 선택 | --manifest 경로·SHA 추적/166개 검사 통과 | 실제 학습·원자료 변경 없음 |
| 실제 학습 | stopped_by_user 원문 동일 | 성능/가설지지 미산출 |
