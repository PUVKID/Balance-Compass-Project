예측 금액의 평균 오차와 실제 금액이 예측 범위에 들어오는 비율을 함께 본다. 작은 오차가 모든 집의 정확한 예측을 뜻하지 않는다. 화면에는 수집 완료와 실험 중지를 따로 표시한다. 없는 결과는 0으로 만들지 않는다.

## 최신 6차

같은 계약이 두 번 들어가면 오차가 달라지고, 자료가 없는 결과를 측정한 것처럼 보이면 논문 해석이 틀어진다. 이번에는 이런 입력과 표시 오류를 막았다. 예를 들어 서울 계약 3건을 비교하기로 했는데 2건만 내면 계산을 진행하지 않는다.

예측 원행은 계약 한 건의 식별표다. 합성은 시험용으로 만든 자료이고 실측은 실제 자료다. 기계 적격은 형식·ID·날짜 검사 통과를 뜻하며 실제 위치나 과거 운영을 입증하지 않는다.

| 변경 | 확인 | 제한 |
|---|---|---|
| 저장 결과·화면 | 원행·분할·모드·서울 집합·수치 정합 | 실측 결과 미측정 |
| 시설 원천 | 4종 원문을 두 기준일로 검사 | 과거 운영·전국 완전성 미입증 |
| 기술 검증 | 145개 검사 통과 | 실제 학습 중지 |
