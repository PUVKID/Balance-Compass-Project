# 신규 연구 1차 구현 계획

명세: 연구설계.md. Python 연구 처리, Rust 금액 처리, 로컬 읽기 전용 조회로 역할을 나눈다. 구 소스 복원으로 표기하지 않는다.

1. 공식 원천·선행연구·이용조건을 확인하고 출처와 제약을 저장한다.
2. 원본 SHA와 출처 manifest를 검증하는 CSV 로더 및 전처리 감사를 구현한다.
3. 고정 시간 분할, 지역 홀드아웃, train-only 전처리와 비교 모델을 구현한다.
4. 유한표본 순위 보정·포함률·구간 폭·interval score를 구현하고 단위/누수/실패 검사를 수행한다.
5. Rust 금액 정규화 CLI를 실제 로더와 연결하고 빌드/오류/정확한 원 단위 일치를 확인한다.
6. 30종 이상 분석 목적 registry와 미측정 상태를 연결한다. 입력/실행 근거가 없는 결과를 채우지 않는다.
7. 코드 전용 Graphify를 생성하고 호출 관계를 소스와 대조한다. 독립 검토로 누락·과학적 한계를 기록한다.
8. 사용자용 실행 안내·실제 완료/미완료 상태·패키지 및 공개 가능 코드 범위를 정리한다.

이 문서 작성 자체는 구현·실험 완료 근거가 아니다. 유효한 동일 검사 결과를 반복하지 않는다.
