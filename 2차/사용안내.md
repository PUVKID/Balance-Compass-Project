# Balance Compass 새 연구 2차 사용 안내

이번 차수는 Windows 로컬에서 다시 만든 연구 도구입니다. **과거 클라우드 ZIP을 복원한 원본이 아닙니다.** 전국 아파트 전세 보증금과 월임대료를 별도 예측하며, 실제 자료를 확보하기 전에는 합성 검증만 수행합니다.

| 시작할 작업 | 실행 파일 | 결과 |
|---|---|---|
| 화면 열기 | `대시보드_시작.ps1` | 기본 주소 `http://127.0.0.1:8776`, 읽기 전용 |
| 실제 자료 검사 | `연구_실행.ps1 validate` | 파일 해시·행 수·금액·제외 사유 확인 |
| 실제 자료 평가 | `연구_실행.ps1 run` | 새 결과 폴더에 표·그림·요약 저장 |
| 합성 처리 확인 | `연구_실행.ps1 smoke` | SYNTHETIC으로 명시한 기술 검증 |

모든 명령은 이 차수 폴더에서 PowerShell로 실행합니다. 기존 1차의 `.venv`가 있으면 실행 파일이 재사용합니다. 새 설치에서는 Python 3.12로 `.venv`를 만든 뒤 `requirements.txt`를 설치합니다. 대시보드는 Python 표준 라이브러리만 사용합니다. 연구 엔진에는 별도 의존성이 필요합니다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\scripts\build_rust.ps1
.\대시보드_시작.ps1
```

Rust 빌드에는 MSVC C++ 도구와 Windows SDK가 필요합니다. 이 컴퓨터의 스크립트는 설치된 Visual Studio와 E에 보존된 SDK를 사용하며 환경변수는 해당 프로세스에서만 적용합니다. 다른 컴퓨터는 해당 경로를 실제 환경에 맞춰 조정하거나 MSVC 개발자 PowerShell에서 `cargo build --release --manifest-path rust_money/Cargo.toml`을 사용합니다. Python 연구 실행은 `rust_money/target/release/bc-money.exe`를 실제 호출합니다. 실행 파일이 없으면 실패하며 Python 계산으로 몰래 대체하지 않습니다.

## 실제 자료 manifest

CSV와 같은 폴더에 manifest JSON을 저장합니다. 아래 값은 **입력 형식 예시**이며 실제 파일·해시·행 수로 교체해야 합니다. 미확인 값을 실측 출처로 입력하지 않습니다. API 키·계좌·개인정보는 넣지 않습니다.

```json
{
  "files": [
    {
      "path": "확보한_원본.csv",
      "sha256": "실제_SHA256_64자리",
      "rows": 100,
      "source_url": "https://rt.molit.go.kr/",
      "acquired_at": "2026-11-26T19:00:00+09:00",
      "snapshot_id": "확보한_스냅숏_식별자",
      "region": "실제 파일 범위",
      "start_month": "202201",
      "end_month": "202512"
    }
  ]
}
```

| CSV 칼럼 | 단위·뜻 | 처리 |
|---|---|---|
| 시군구 | 원본 지역명 | 지역 feature 및 결과 집계 |
| 전용면적(㎡) | ㎡ | 유효한 양수 |
| 계약년월·계약일 | YYYYMM·일 | 실제 달력 날짜 확인 |
| 보증금(만원)·월세금(만원) | 만원 문자열 | Rust가 정확한 원 정수로 변환 |
| 층·건축년도 | 층·연도 | 이상값 감사 후 제외 |
| 계약구분 | 신규 / 갱신 / 미상 | 주분석은 신규, 나머지 사유 기록 |

공식 내려받기 파일에 제목·설명 행이 있거나 칼럼 이름이 다르면 그대로 읽을 수 없습니다. 현재 로더는 위 머리글을 가진 UTF-8 또는 CP949 CSV를 받습니다. 원본을 덮어쓰지 않고 별도 정규화 파일을 만들며 취득 원본과의 관계를 보존해야 합니다. 원본 해시 검사는 파일 내용의 정확성을 보장하지 않습니다.

```powershell
.\연구_실행.ps1 validate --manifest "실제 자료 폴더/manifest.json"
.\연구_실행.ps1 run --manifest "실제 자료 폴더/manifest.json" --output "results/실측_첫실행"
.\대시보드_시작.ps1 --result "results/실측_첫실행" --port 8777
```

지역 이동 평가는 별도 출력 경로로 실행합니다. `--holdout-region`은 해당 지역을 학습·검증·보정에서 모두 제외하며 최종 테스트에서만 평가합니다. 시간 평가와 다른 실험이므로 출력과 해석을 분리합니다.

```powershell
.\연구_실행.ps1 run --manifest "실제 자료 폴더/manifest.json" --output "results/지역이동_첫실행" --holdout-region "서울특별시"
.\연구_실행.ps1 smoke --output "results/합성_처리확인"
```

## 결과와 한계

| 결과 | 의미 | 주의 |
|---|---|---|
| summary.json | 원값 지표·분할 표본·출처·감사·산출물 목록 | 내부 출처 경로는 공개 저장소에 넣지 않음 |
| 분석 CSV·PNG | 동일 분석의 원자료와 시각화 | 두 파일을 두 종류로 세지 않음 |
| 예측 CSV | 실제값·예측값·예측구간 | 개인 자료·실측 행은 비공개 |
| audit_rows.csv | 행별 제외 사유 포함 | 원본은 수정하지 않음 |
| REAL | 사용자가 제공한 CSV 처리 | 전국 완결성 인증이 아님 |
| SYNTHETIC | 결정론적으로 만든 기술 검증 자료 | 실제 예측 성능이 아님 |

금액 형식 오류는 Rust 전체 검증을 실패시키며 부분 결과를 출력하지 않습니다. 기존 출력 폴더가 있으면 덮어쓰지 않습니다. 신규계약 부재·빈 시간 분할·자료 누락도 실패합니다. 오류를 0점이나 완료 상태로 바꾸지 않습니다.

전국 원본 수집, 공식 지역 코드에 따른 완결성 대조, 지역별 conformal·분위수 구간 비교·단지 부트스트랩·신고 지연·갱신 민감도와 논문은 미완료입니다. 현재 구현으로 전국 연구와 논문이 완성됐다고 해석하면 안 됩니다.
