# 새 연구 2차 변경 기록

2026-11-26. 로컬 최신 설계와 Rust 금액 코드를 이어서 연구 엔진·결과 조회 화면을 신규 구현했다.

| 변경 | 파일 | 이유 |
|---|---|---|
| 연구 처리 추가 | rentlab/engine.py, rentlab/__main__.py | 원본 검사부터 예측 평가까지 실제 처리 경로 연결 |
| 금액 처리 연결 | rust_money/src/main.rs, scripts/build_rust.ps1 | 원 단위 정수 정규화와 Windows 빌드 환경 연결 |
| 화면 추가 | run_dashboard.py, web/index.html, web/style.css, web/app.js | 실제 결과·합성 검증·미연결 상태를 읽기 전용으로 확인 |
| 실행·안내 | 연구_실행.ps1, 대시보드_시작.ps1, 사용안내.md | 새 채팅과 별개로 로컬 실행 |
| 검사 | tests/test_engine.py | 입력 보존·분할·보정·모델 선택 오류 확인 |
| 글꼴 | web/NanumGothic-Bold.ttf, web/OFL.txt | 나눔고딕700과 원본 OFL 동봉 |

검증된 최종 상태와 미완료 항목은 [사용 안내](사용안내.md), 연구 방법은 [연구설계](docs/연구설계.md), 직전 비교는 [차수 비교](docs/차수비교.md)를 따른다. 이 변경 기록은 실제 전국 학습 완료·논문 게재·과거 클라우드 첨부 복원을 주장하지 않는다.
