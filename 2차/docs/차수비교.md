# 새 연구 1차 → 2차 전체 비교 안내

| 항목 | 1차 | 2차 |
|---|---|---|
| 연구설계 | 설계 문서 | 원문 계승, 실제 구현·한계 안내 추가 |
| 금액 정규화 | Rust 소스만 있음 | 동일 소스 보존, Python 실제 호출 및 Windows 빌드 연결 |
| 데이터 처리 | 구현 계획 | manifest 해시·행 수 검사, CSV 정제·감사 |
| 평가 | 구현 계획 | 고정 시간 분할·지역 홀드아웃·네 모델·분할 conformal |
| 산출물 | 계획 | 35 목적 목록, 계산 가능 30종과 미측정 5종 구분 |
| 화면 | 없음 | 읽기 전용 서버, 5개 화면, 테마 저장·설명 카드·파일 조회 |
| 실제 자료·전국 성능 | 미확보·미실행 | 미확보·미실행 유지 |

Rust `src/main.rs`, `Cargo.toml`, `Cargo.lock`과 연구설계는 1차에서 가져왔습니다. `.venv`, 빌드 중간물과 공식 자료제공 HTML 사본은 신규 코드로 복제하지 않았습니다. 과거 V10 소스 조각을 복원한 것으로 표기하지 않습니다.

실제 공개 가능한 텍스트의 전체 차이는 [전체차이.diff](전체차이.diff)에 저장합니다. 추가 파일은 전체 본문, 수정 파일은 공백·주석을 포함해 비교합니다. 글꼴 등 바이너리는 공개 파일 목록의 바이트·SHA-256으로 구분합니다. 비공개 원본·운영 로그·대화·실측 CSV·인증자료는 비교에서 제외합니다.
