# 새 연구 2차 재구성 계획

2026-11-26. 기존 채팅 대신 새 로컬 채팅에서 진행한다. 구 V10 원본 복구와 신규 구현을 구분한다.

| 구성 | 구현과 확인 |
|---|---|
| 연구 엔진 | manifest 해시 확인 → Rust 원 단위 변환 → 고정 시간 분할 → 검증셋 모델 선택 → 보정 → 최종 평가 |
| 실행 연결 | Python CLI, Rust 빌드, 읽기 전용 로컬 HTTP 서버. 이전 차수 환경을 재사용하되 새 설치 환경도 안내 |
| 화면 | 지정 블루·퍼플, 나눔고딕700, 왼쪽 탐색, 라이트·다크 저장, 실제 결과와 합성 결과 구분 |
| 결과 보존 | 기존 입력과 출력 덮어쓰기 금지. 실측 자료가 없으면 전국 완료·성과로 표시하지 않음 |
| 확인 | 금액 오류·해시 불일치·시간 누수·작은 보정 표본·서버 파일 경계·테마·좁은 화면 |

연구설계.md를 계승한다. 구현 방법은 Python + Rust + 별도 빌드가 필요 없는 HTML/CSS/JavaScript로 결정했다. 서버는 127.0.0.1에만 바인딩하며 실행·학습·수집 API를 제공하지 않는다.

과거 CSV 209개와 클라우드 결과는 로컬에 없으며 이번 차수의 입력으로 사용하지 않는다. 실제 자료 수집·전국 커버리지 확인·본실험과 논문은 별도의 미완료 항목으로 기록한다. 자동 생성한 합성 자료는 처리 기능 확인에만 사용한다.
