# 전국 아파트 임대료 AI 예측의 시공간 일반화와 예측구간 신뢰성

2026-11-26. 신규 구현. 과거 V10.3을 복구한 소스가 아니다.

사용자는 기존 ZIP 대신 새 연구·코드·데이터 검증을 직접 요청했다. 구현 선택은 수행자가 정했으며 사용자가 최종 연구 설계를 승인했다고 기록하지 않는다.

| 질문 | 비교와 검증 |

전국 예측 자체는 기존 연구와 겹친다. 차별성 후보는 시간 변화와 지역별 구간 신뢰성의 실증 분석이다. 전수 문헌조사나 독창성 확정은 아직 아니다.

## 데이터 계약

공식 원천: https://www.data.go.kr/data/15126474/openapi.do 및 https://rt.molit.go.kr/pt/xls/xls.do . 2021-2025의 완료된 계약연도를 우선 계획한다. 2021년 6월 신고제 전후의 수집 체계 차이는 별도 민감도 분석 대상이며 주분석 시작 후보는 2022년이다. 전국 지역 목록은 공식 수집 시점의 코드 목록으로 동결하며 현재 코드를 과거 행정경계와 동일하다고 가정하지 않는다.

실거래 공개 스냅숏은 전체 임차가구 모집단이 아니고, 과거 시점에 공개됐던 정보의 완전한 재현도 아니다. 신고 지연·사후 수정 및 누락으로 인한 한계를 반드시 명시한다. 계약일을 아는 사후 자료로 평가한 결과는 계약 체결 전 실시간 예측 성과로 확대하지 않는다.

각 원본에 SHA-256·출처 URL·취득 시각·요청 조건·응답 상태·행 수·스냅숏 ID를 기록한다. API 키는 환경변수에서만 읽고 로그에 기록하지 않는다. 제한·인증 실패를 우회하거나 빈 응답을 성공 데이터로 처리하지 않는다.

전세는 월세 0인 계약의 보증금(원), 월세는 양수 월임대료(원)를 별도 목표로 분석한다. 월세 목표에서 보증금은 관측된 계약조건으로만 해석하며 인과적 대체계약을 추정하지 않는다. 계약 구분 미상·갱신·해제·건축연도 이상·금액 이상은 각각 집계하고 원문을 보존한다. 주분석 신규계약과 갱신/미상 민감도를 분리한다. 정확히 같은 공개 행은 서로 다른 실제 계약일 수 있으므로 자동 중복 삭제하지 않는다. 여러 원본 파일의 범위 중복은 파일 메타데이터로 차단한다.

## 평가 원칙

최종 2025년 테스트를 모델 선택에 사용하지 않는다. 2022-2023 학습, 2024 상반기 검증, 2024 하반기 보정, 2025 테스트를 첫 고정 프로토콜로 사용한다. 2024년 테스트는 더 이른 자료 확보 시 추가하며 없는 과거를 만들어 쓰지 않는다. 전처리·범주 사전·집계는 학습셋에서만 추정한다. 랜덤 행 분할은 비교를 위한 누수 위험 진단으로만 사용할 수 있고 주성능으로 제시하지 않는다.

분할 conformal의 유한표본 보장은 교환가능성 등 가정에 의존한다. 시간·지역 이동 환경에서 90% 보장을 선언하지 않고 포함률을 실측한다. 보정 표본 부족은 미산출 또는 명시된 전체 보정 대체로 표시한다. 아파트/단지 군집 부트스트랩 및 여러 연도·지역 반복은 구현과 실제 실행 여부를 구분한다.

소규모 기술 검증은 전국 본실험과 구분한다. 실제 자료가 없으면 합성 검증만 수행하고 REAL 결과를 만들지 않는다. 유리한 모델·지역만 골라 전체 성과로 표시하지 않는다. 30종 이상 그림·표는 서로 다른 분석 목적의 목록으로 관리하며 동일 CSV/PNG는 한 종류다.

## 구현과 실행

Python 연구 파이프라인 + Rust 원 단위 금액 정규화 실제 호출. CPU만 사용. 원천자료·모델·실험 출력은 GitHub 공개 대상과 분리한다. 대시보드는 읽기 전용이며 데이터 누락·합성/실측·전국 커버리지를 분명히 표시한다. 나눔고딕700·지정 블루/퍼플·라이트/다크 저장 기준을 유지한다.

본 차수의 첫 완료 범위는 데이터 취득 경로 확인, 실행 가능한 정제/분할/평가 기반, 누수·단위·실패경로 검사와 실제 가능한 데이터 확보다. 전국 본실험·논문 완성·게재는 실제 근거가 확보될 때 별도로 표시한다.
