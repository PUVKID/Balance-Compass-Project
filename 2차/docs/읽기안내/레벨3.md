**전국 실측 본실험은 미실행이다.** 아래 구현과 합성 검증을 실측 성능으로 해석하지 않는다.

<a id="reading-level-3"></a>






Python 3.12와 의존성, Rust MSVC 빌드 환경을 준비한다. 먼저 Rust 바이너리를 만들고 실제 자료를 검사한 뒤 새 출력 경로로 연구를 실행한다. 화면 서버는 기존 결과를 읽을 뿐 연구·수집 API를 제공하지 않는다. 기본 바인딩은 127.0.0.1이며 외부 서비스 배포를 위한 인증 서버가 아니다.

| 명령 | 목적 | 실패 조건 |
|---|---|---|
| `scripts/build_rust.ps1` | 금액 CLI 빌드 | 링커·SDK 부재 |
| `python -m rentlab validate --manifest 경로` | 실제 입력 검사 | 해시·행 수·칼럼·금액 오류 |
| `python -m rentlab run --manifest 경로 --output 새폴더` | 실측 입력 평가 | 기존 출력·빈 분할·신규계약 부재 |
| `python -m rentlab smoke --output 새폴더` | 합성 기술 검증 | 기존 결과 덮어쓰기 거부 |
| `python run_dashboard.py --result 결과폴더` | 결과 조회 | summary 부재·유형 오류 |

금액은 만원 문자열에서 원 정수로 변환한다. 쉼표 위치·정밀도·범위를 Rust에서 검사하며 임의 실수 변환으로 대체하지 않는다. 잘못된 금액 한 행은 전체 처리를 실패시키며 부분 출력을 남기지 않는다. 기타 날짜·계약구분 이상은 감사 사유로 제외한다. 원본과 기존 결과는 보존한다. 셋업·manifest 예시·홀드아웃 명령은 [사용 안내](../../사용안내.md)를 참조한다. 루트 실행 스크립트는 자기 차수의 `.venv`를 우선하며 로컬 1차 환경이 있으면 명시적으로 재사용한다.
