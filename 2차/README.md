# Balance Compass

전국 아파트 임대료 예측과 예측구간 신뢰성 연구

[사용 안내](사용안내.md) · [연구설계](docs/연구설계.md) · [전체 차수](docs/차수목록.md) · [차수 비교](docs/차수비교.md) · [변경 기록](변경기록.md)

</div>

공식 CSV의 출처와 무결성을 확인하고, 전세 보증금과 월임대료를 별도 예측한다. 시간 분할과 지역 홀드아웃으로 평균 오차와 예측구간 포함률을 평가한다. Python 연구 처리에 Rust 금액 정규화를 연결했고, 결과를 로컬 읽기 전용 화면에서 확인한다.

**현재 실제 전국 자료는 미확보이며 전국 본실험은 미실행이다.** 합성 검증은 프로그램의 기술 확인이며 실제 예측 성능이 아니다. 이 저장소는 과거 V10 ZIP 복원본이 아닌 새 연구 2차의 신규 구현이다. 논문 원고·게재 성과는 아직 없다.

과거 클라우드 V10과 로컬 새 연구의 번호는 별개다. 과거 파일·데이터 실물 없이 3~10차를 새로 만들지 않는다. 현재 공개 소스는 새 연구 1차에서 확인한 설계와 Rust 원본을 보존하며 2차 실행 경로를 사용한다.

<details><summary>LEVEL 1 - Beginner · 연구와 결과 읽기</summary>
<a id="reading-level-1"></a>

[같은 수준의 1차](history/1차/차수설명.md#user-content-reading-level-1) · [2차 전체 안내](docs/읽기안내/레벨1.md)





집의 임대료를 한 숫자로 맞히는 것과, 오차가 어느 정도인지 설명하는 것은 다른 문제다. 이 연구는 전세 보증금과 월세를 따로 예측하고 실제값이 예측 범위 안에 얼마나 들어오는지 확인한다. 화면의 MAE는 실제 금액과 예측 금액 사이 평균 차이다. 숫자가 작으면 평균 오차가 작다는 뜻이지만 모든 집을 정확히 맞힌다는 뜻은 아니다.

| 화면 | 확인할 내용 | 해석 |
|---|---|---|
| 연구 현황 | 실제 자료·합성 자료·미연결 상태 | 합성 결과를 전국 결과로 읽지 않는다 |
| 데이터 점검 | 원본 행 수와 제외 사유 | 제외된 계약도 감사 기록으로 남는다 |
| AI 평가 | 비교 모델의 오차와 포함률 | 포함률과 구간 폭을 함께 본다 |
| 표와 그림 | 계산된 분석과 미산출 목적 | 없는 결과를 0으로 채우지 않는다 |

현재 전국 본실험이 끝나지 않았으므로 이 도구의 예시 수치로 실제 주거 계약을 판단할 수 없다. 월세 예측은 이미 관측한 보증금 조건을 사용한다. 보증금을 바꾸면 월세가 반드시 그만큼 달라진다는 인과관계를 계산하는 기능은 아니다. 실행은 [사용 안내](사용안내.md)에 따라 준비한다. 같은 차수의 실제 구현은 [2차 비교](docs/차수비교.md)에서 확인한다.

</details>

<details><summary>LEVEL 2 - Explorer · 자료와 실행 흐름</summary>
<a id="reading-level-2"></a>

[같은 수준의 1차](history/1차/차수설명.md#user-content-reading-level-2) · [2차 전체 안내](docs/읽기안내/레벨2.md)





입력은 국토교통부 공개 CSV와 파일별 manifest다. manifest에는 파일 이름뿐 아니라 SHA-256, 행 수, 취득 시각, 출처와 스냅숏 식별자가 들어간다. 해시는 프로그램이 읽는 파일과 기록한 파일이 같은지 검사한다. 그 내용이 실제 모집단을 완전히 대표한다는 뜻은 아니다.

| 단계 | 입력 | 출력 |
|---|---|---|
| 자료 검사 | 원본 CSV·manifest | 해시·행 수·중복 범위 검사 |
| 정제 | 금액·날짜·계약구분 | 분석 행과 제외 사유 |
| 비교 학습 | 2022–2023 계약 | 중앙값·지역 중앙값·Ridge·트리 부스팅 |
| 선택·보정 | 2024 상반기·하반기 | 선택 모델과 보정 반경 |
| 최종 평가 | 2025 계약 | 오차·구간·지역 집계·표·그림 |

학습에 쓰는 기간, 모델을 고르는 기간, 예측구간을 보정하는 기간, 마지막 평가 기간을 나눈다. 나중에 나온 답을 미리 학습에 넣는 일을 줄이기 위해서다. 실제 자료가 없을 때 `smoke` 명령으로 기술 흐름을 확인할 수 있지만 결과에는 SYNTHETIC이 표시된다. 현재 목록은 35 분석 목적이며 계산 가능한 30종과 구현·입력이 부족한 5종을 구분한다. CSV와 PNG가 한 쌍이면 한 분석이다. 상세 실행은 [사용 안내](사용안내.md), 연구 목적은 [연구설계](docs/연구설계.md)를 따른다.

</details>

<details><summary>LEVEL 3 - Practitioner · 실행과 오류 처리</summary>
<a id="reading-level-3"></a>

[같은 수준의 1차](history/1차/차수설명.md#user-content-reading-level-3) · [2차 전체 안내](docs/읽기안내/레벨3.md)





Python 3.12와 의존성, Rust MSVC 빌드 환경을 준비한다. 먼저 Rust 바이너리를 만들고 실제 자료를 검사한 뒤 새 출력 경로로 연구를 실행한다. 화면 서버는 기존 결과를 읽을 뿐 연구·수집 API를 제공하지 않는다. 기본 바인딩은 127.0.0.1이며 외부 서비스 배포를 위한 인증 서버가 아니다.

| 명령 | 목적 | 실패 조건 |
|---|---|---|
| `scripts/build_rust.ps1` | 금액 CLI 빌드 | 링커·SDK 부재 |
| `python -m rentlab validate --manifest 경로` | 실제 입력 검사 | 해시·행 수·칼럼·금액 오류 |
| `python -m rentlab run --manifest 경로 --output 새폴더` | 실측 입력 평가 | 기존 출력·빈 분할·신규계약 부재 |
| `python -m rentlab smoke --output 새폴더` | 합성 기술 검증 | 기존 결과 덮어쓰기 거부 |
| `python run_dashboard.py --result 결과폴더` | 결과 조회 | summary 부재·유형 오류 |

금액은 만원 문자열에서 원 정수로 변환한다. 쉼표 위치·정밀도·범위를 Rust에서 검사하며 임의 실수 변환으로 대체하지 않는다. 잘못된 금액 한 행은 전체 처리를 실패시키며 부분 출력을 남기지 않는다. 기타 날짜·계약구분 이상은 감사 사유로 제외한다. 원본과 기존 결과는 보존한다. 셋업·manifest 예시·홀드아웃 명령은 [사용 안내](사용안내.md)를 참조한다. 루트 실행 스크립트는 자기 차수의 `.venv`를 우선하며 로컬 1차 환경이 있으면 명시적으로 재사용한다.

</details>

<details><summary>LEVEL 4 - Advanced · 분할과 모델 검토</summary>
<a id="reading-level-4"></a>

[같은 수준의 1차](history/1차/차수설명.md#user-content-reading-level-4) · [2차 전체 안내](docs/읽기안내/레벨4.md)





전처리의 중앙값·범주 사전·스케일러와 지역별 중앙값은 학습 분할에서만 추정한다. 검증 MAE로 모델을 선택하며 최종 테스트를 모델 선택에 사용하지 않는다. 선택 모델을 기준으로 보정 분할의 절대 잔차를 계산한다. 지역 홀드아웃에서는 지정 지역을 앞의 세 분할에서 모두 제외하고 그 지역의 2025 계약을 평가한다.

| 요소 | 현재 구현 | 검토할 한계 |
|---|---|---|
| 기준 모델 | 전체·지역 중앙값 | 미관측 지역은 학습 전체 중앙값 |
| AI 모델 | Ridge·HistGradientBoosting | 고정 설정, 광범위 탐색 미수행 |
| 특징 | 지역·면적·층·건물 연령·월 | 월세에는 관측 보증금 추가 |
| 보정 | 절대 잔차 split conformal | 지역별 별도 보정과 분위수 모델 미구현 |
| 지역 집계 | 지역별 MAE·포함률·표본 | 적은 표본·지역 경계 변화에 주의 |

시간 분할이 신고 시차와 공개 시점의 완전한 재현을 뜻하지 않는다. 사후 공개 스냅숏의 계약일을 쓰므로 실시간 예측 성과로 확대할 수 없다. 같은 공개 행이 실제로 별도 계약일 수 있어 행을 무조건 중복 삭제하지 않는다. 파일 간 같은 지역·계약월 범위는 병합 전에 거부한다. 최종 소스의 검사와 실측 연구의 통계적 타당성은 구분해야 한다. [연구설계](docs/연구설계.md)와 [전체 차이](docs/전체차이.diff)를 함께 검토한다.

</details>

<details><summary>LEVEL 5 - Expert · 재현과 통계 가정</summary>
<a id="reading-level-5"></a>

[같은 수준의 1차](history/1차/차수설명.md#user-content-reading-level-5) · [2차 전체 안내](docs/읽기안내/레벨5.md)





보정 표본 n과 alpha=0.1에 대해 `ceil((n+1)*(1-alpha))` 순위의 절대 잔차를 선택한다. 순위가 n을 넘으면 구간을 산출하지 않고 null로 남긴다. 유한표본 포함률 보장은 교환가능성 등의 가정에 의존하며 시간·지역 이동 환경에 무조건 적용할 수 없다. 테스트에는 MAE, RMSE, 구간 포함률, 평균 폭, interval score와 표본 수를 저장한다. 원비율은 보존하며 UI 백분율만 소수 첫째 자리로 반올림한다.

| 재현 요소 | 기록·동작 | 미완료 범위 |
|---|---|---|
| 입력 | 원본 SHA-256·출처·시각·스냅숏 | 전국 완결성 공식 코드 대조 |
| 금액 | i64 원 단위, Rust 바이너리 해시 | 속도 향상 전후 실측 없음 |
| 모델 | CPU, 부스팅 random_state=42 | 불확실성 반복실험·하이퍼파라미터 탐색 |
| 평가 | train-only 전처리·고정 시간·지역 홀드아웃 | 단지 군집 부트스트랩 |
| 민감도 | 미측정 상태를 결과 목록에 보존 | 신고 지연·갱신·지역 conformal·분위수 비교 |
| 출력 | 기존 폴더 보호·임시 폴더 완성 후 이름 변경 | 대규모 전국 입력의 메모리·시간 실측 |

공개 자료는 임차가구 모집단 전체가 아니다. 지역명은 행정구역 코드의 역사적 동등성을 보장하지 않는다. 금액의 정확한 정수 정규화 이후 회귀·평가에는 부동소수 계산을 사용한다. 실제 데이터·모델·내부 출처·개인정보·인증자료는 이 저장소에 넣지 않는다. 나눔고딕은 [OFL](web/OFL.txt)을 동봉했다. 현재 구현 상태와 남은 연구를 함께 해석하고, 합성 검사 성능을 실측 연구 성과로 인용하지 않는다. 구현 원문은 [엔진](rentlab/engine.py), 입력·실행 계약은 [사용 안내](사용안내.md)에서 확인한다.

</details>
