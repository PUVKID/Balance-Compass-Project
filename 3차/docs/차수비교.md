# 2차 → 3차

| 구분 | 추가·수정 | 검증 기준 | 제한 |
|---|---|---|---|
| 입력·금액 | 월/층/연도·혼합 취소·원문 중복 감사 | 경계 fixture·기존 정상 입력 회귀 | 원문 정확성이 현실 계약 식별을 보장하지 않음 |
| 모델 | 목표별 가격 경계·지역 인코딩·후보별 테스트 저장 | 학습 전용 경계·분할 검사 | 실제 대규모 완료 성능 미확인 |
| 실행 | 단일 실행 잠금·복구 저널·중단 상태·H5 연결 | 가짜 엔진과 실제 수식 writer 통합 | 실제 학습 재시작 안 함 |
| UI | 진행·이전 자료 표시·가설·홀드아웃·차트 축약 | HTTP·DOM·브라우저 점검 | 결과 없는 수치를 생성하지 않음 |
| 수식 | 8가설·15평가·cluster bootstrap·제안 조합지표 | 손계산 대조·독립 재현 | 근사 추론·제안 지표의 검증 전 상태 |

학습·수집·실제 원자료는 삭제하지 않았다. 부스팅 early_stopping은 2차 auto에서 3차 False(고정80회)로 바뀌었다. 이전 코드의 결과와 동일한 모델이라 주장하지 않는다. 공백·주석을 포함한 전체 파일 차이는 공개 묶음의 전체차이.diff에 보존한다.
