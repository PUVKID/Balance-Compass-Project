공식 공개 CSV를 검사하고 전세 보증금·월임대료를 별도 예측한다. Python 연구 처리와 Rust 원 단위 정규화, 읽기 전용 대시보드를 연결했다. 3차는 입력·실행·화면 오류 수정과 학습 후 자동 가설 분석을 추가한다.

**2022–2025년 48개월, 원문 4,845,086행을 확보했다. 실제 실험은 사용자 요청으로 중지되어 있으며 완료된 실측 성능은 없다.** 이 행 수는 정제 후 학습 행 수가 아니다. 합성 검사는 기술 검증이다. 논문 원고·게재 성과는 아직 없다. 과거 클라우드 V10 복원본이 아닌 별도 새 연구다.

<a id="reading-level-1"></a>
## LEVEL 1 - Beginner

예측 금액의 평균 오차와 실제 금액이 예측 범위에 들어오는 비율을 함께 본다. 작은 오차가 모든 집의 정확한 예측을 뜻하지 않는다. 화면에는 수집 완료와 실험 중지를 따로 표시한다. 없는 결과는 0으로 만들지 않는다.

| 확인할 곳 | 의미 | 주의 |
|---|---|---|
| 진행 상태 | 수집 48개월 완료·실험 중지 | 수집 완료가 학습 완료는 아님 |
| 예측 평가 | 전세·월세 오차와 구간 | 두 금액을 섞어 비교하지 않음 |
| 가설 8개 | 사전에 정한 질문의 수치 평가 | 표본 부족은 미산출·판정 보류 |

[같은 수준 상세](docs/읽기안내/레벨1.md). 월세는 관측 보증금 조건의 예측이며 계약조건의 인과효과를 계산하지 않는다.

<a id="reading-level-2"></a>
## LEVEL 2 - Explorer

원본 SHA·행 수·출처를 검사하고 새 폴더에 정제·예측·가설 결과를 저장한다. 이미 있는 출력은 덮어쓰지 않는다. 기존 자료는 보존하고 단지·원행 연결 키는 별도 로컬 변환으로 추가한다.

| 단계 | 기간·자료 | 산출 |
|---|---|---|
| 학습 | 2022–2023 | 전처리·모델·가격 경계 |
| 선택 | 2024 상반기 | 검증 MAE 최소 모델 |
| 보정 | 2024 하반기 | 전체·지역 구간 반경 |
| 최종 평가 | 2025 | 예측 CSV·15개 가설 평가 |

[같은 수준 상세](docs/읽기안내/레벨2.md). 대시보드는 결과를 읽으며 학습을 시작하는 버튼은 없다.

<a id="reading-level-3"></a>
## LEVEL 3 - Practitioner

Python 3.12와 requirements, Rust CLI를 준비한다. 수집·실험 실행기는 기본으로 계획만 출력한다. `--execute`를 명시해야 실행한다. 중단 상태는 자동 재시작하지 않는다.

| 명령 | 동작 | 보호 조건 |
|---|---|---|
| `python -m rentlab validate --manifest 경로` | 입력 검사 | 해시·행 수·칼럼·금액·월 형식 |
| `python -m rentlab smoke --output 새폴더` | 합성 기술 검사 | 실측 성과로 판정하지 않음 |
| `python -m rentlab.experiment_runner --root 자료 --run-dir 새폴더 --with-holdout 서울특별시` | 두 실행의 계획 | execute 없으면 무쓰기 |
| `python run_dashboard.py --result 결과폴더` | 읽기 전용 조회 | 엄격 summary·파일 허용 목록 |

[실행 명세](사용안내.md) · [같은 수준 상세](docs/읽기안내/레벨3.md). 단일 실행 잠금·원자적 상태 저장·KeyboardInterrupt 중단 처리를 사용한다.

<a id="reading-level-4"></a>
## LEVEL 4 - Advanced

학습 분할에서만 전처리·범주·중앙값을 추정한다. AI 후보와 기준 모델은 검증에서 선택한다. 부스팅은 80회 고정(early_stopping=False), Ridge는 희소 지역 인코딩을 쓴다. 지역 홀드아웃은 서울을 학습·검증·보정에서 모두 제외한다.

| 분석 | 비교 | 제한 |
|---|---|---|
| H1·H2 | AI/기준·보증금 특징 제외 | 예측 파이프라인 비교, 인과 아님 |
| H3·H4 | 전체·지역 포함률 | 동등성 ±2%p, 지역 편차와 이질성 구분 |
| H5·H6 | 서울 이동·가격대 오차 | 동일 계약 짝맞춤·학습 경계 고정 |
| H7·H8 | 지역 보정·반기 감소 | 적격 지역·최소 단지 조건 |

[수식 명세](docs/논문_가설과_수식.md) · [같은 수준 상세](docs/읽기안내/레벨4.md). 신고 지연·갱신·분위수 모델 민감도는 미측정이다.

<a id="reading-level-5"></a>
## LEVEL 5 - Expert

잔차 순위 ceil((m+1)×0.90)의 split conformal을 쓴다. 단지 군집 percentile bootstrap 9,999회와 15평가 Bonferroni 원칙을 적용한 근사 구간을 계산한다. 시간 이동에서 90% 포함률이나 정확한 가족 95% 보장을 주장하지 않는다. 모델 재학습 불확실성은 포함하지 않는다.

| 재현 요소 | 기록 | 경계 |
|---|---|---|
| 자료 | 원본 SHA·스냅숏·요청 조건 | 역사적 지역·모집단 완전성 미검증 |
| 모델 | 버전·설정·분할·후보 예측 | 고정 CPU 설정, 대규모 완료 성능 없음 |
| 가설 | 효과·구간·n·군집·유효 반복·코드 SHA | 표본 부족은 partial/unmeasured |
| 제안 지표 | BC_loss·3개 가중치 민감도 | 검증 전 조합 지표, 모델 선택에 미사용 |
