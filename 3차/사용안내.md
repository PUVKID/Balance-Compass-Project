# 3차 사용 안내

실제 실험은 중지 상태다. 아래는 준비된 명령 명세이며 이 문서 작성으로 학습을 재시작하지 않았다. 1·2차 원본과 실제 실험 1차를 보존한다.

## 환경과 기술 검사

Python 3.12, `pip install -r requirements.txt`. 수집 기능은 `pip install -r requirements_acquire.txt`도 필요하다. Rust는 `scripts/build_rust.ps1`로 빌드한다. 로컬 PowerShell 실행기는 같은 차수 .venv를 우선하고 있으면 ../1차/.venv를 재사용한다.

```powershell
python -B -X utf8 -m unittest discover -s tests -q
python -B -X utf8 -m rentlab smoke --output '새_합성검사_폴더'
```

합성 결과는 프로그램 검사용이다. 전국 실측 성능·가설 지지 근거가 아니다.

## 실제 자료와 행 연결 키

공식 CSV는 48개월·원문 4,845,086행을 확보했다. 기존 실제 실험/1차의 9열 변환 자료는 보존한다. 단지 군집과 동일 계약 비교에 필요한 키를 추가하려면 원본 영수증을 검사하여 **새 폴더**에 로컬 변환한다. 먼저 execute 없는 계획을 확인한다.

```powershell
python -B -X utf8 -m rentlab.acquire --root '실제 실험/1차' --local-only --enrich-output '새_입력_폴더'
# 아래는 명시적 실행 명세. 현재 자동 실행하지 않음.
python -B -X utf8 -m rentlab.acquire --root '실제 실험/1차' --local-only --enrich-output '새_입력_폴더' --execute
```

실제 사용할 때 root/출력 경로를 절대경로로 지정한다. 원본 hash·크기·행 수·요청 조건이 다르면 중단한다. 출력이 이미 있으면 거부한다. 작업이 실패한 출력은 검사하고 새 경로로 실행한다. 네트워크 수집은 local-only 없이 별도 새 root에서 execute를 줄 때만 동작하며 하루 100회 제한과 시도 기록을 사용한다.

## 학습 후 자동 가설 분석

```powershell
python -B -X utf8 -m rentlab.experiment_runner --root '새_입력_폴더' --run-dir '새_실행_폴더' --with-holdout 서울특별시
```

기본은 계획만 출력한다. 명시적 `--execute`가 있어야 일반 시간 분할·서울 제외 학습·별도 통합 분석을 실행한다. 미지정 시 단일 일반 실행이고 H5는 미산출이다. 새 run-dir에 결과/홀드아웃결과/가설통합결과를 분리한다. 기존 학습진행.json·결과는 덮어쓰지 않는다. 실행 잠금·고유 임시 파일·중단 상태 보존을 사용한다.

| 파일 | 용도 |
|---|---|
| 자료_manifest.json | 입력 출처·행 수·SHA 검사 |
| *_predictions.csv | 테스트 정답·후보 예측·행·단지 키 |
| *_calibration_predictions.csv | 2024 하반기 보정 결과 |
| hypothesis_results.json / CSV | 8가설·15평가·미산출 이유·신뢰구간 |
| summary.json | 모드·버전·모델·분할·가설 요약 |

세부 가설·계수·판정 조건·문헌은 [수식 명세](docs/논문_가설과_수식.md)를 따른다. 원 단위 금액은 Rust i64 정규화이며 이후 회귀·통계 계산은 부동소수다.

## 대시보드

```powershell
python run_dashboard.py --port 8776 --progress '실제_학습진행.json' --collection-progress '실제_수집진행.json'
python run_dashboard.py --port 8776 --result '완료된_결과_폴더'
```

브라우저에서 http://127.0.0.1:8776/ 를 연다. 결과 미연결 시에도 실제 중단·수집 기록을 표시할 수 있다. 완료된 결과를 연결하면 가설 표를 자동 표시한다. 가설과 수식 안내는 /formulas.html이다. 읽기 전용 로컬 서버이며 수집·학습 실행 API는 없다. 오류 시 이전 자료 표시 안내를 확인한다. 잘린 차트는 전체 CSV와 표시 행 수를 함께 확인한다.
