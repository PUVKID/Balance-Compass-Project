# 새 연구 1차 보존 설명

2026-11-26 로컬에서 확인한 초기 차수다. 설계 문서 두 개, Rust 금액 정규화 소스·Cargo 설정과 빌드 스크립트가 있었다. 연구용 Python 파이프라인과 화면은 없었다. 이 폴더에는 그 공개 가능한 원문만 바이트를 보존해 넣었다.

| 자료 | 당시 역할 | 다음 차수 |
|---|---|---|
| [연구설계](docs/연구설계.md) | 전국 시공간 예측·구간 신뢰성 계획 | [2차 구현](../../사용안내.md) |
| [구현계획](docs/구현계획.md) | 데이터·모델·검증 구현 순서 | [차수 비교](../../docs/차수비교.md) |
| [금액 소스](rust_money/src/main.rs) | 만원 문자열 → 원 정수 | [현재 엔진](../../rentlab/engine.py) |

직전 로컬 신규 연구 차수는 확인되지 않았으므로 초기 차수로 기록한다. 과거 클라우드 V10의 실제 소스와 동일하다고 주장하지 않는다. 1차 빌드 스크립트는 당시 원문이며 현재 실행에는 2차의 스크립트를 사용한다.
