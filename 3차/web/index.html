해석할 때 확인할 점

    검증 기간 모델 비교

    낮은 평균 절대오차가 우선입니다

    최종 테스트

    90%는 명목수준입니다. 시간·지역 이동에서도 90%를 보장한다는 뜻은 아닙니다.

    지역별 결과

    고정 연구 가설 8개 · 목표별 평가 15개

    자동 산출된 효과와 불확실성을 확인합니다. 입력이 없으면 미산출입니다. 가설·수식·출처 읽기

    분석 산출물

    측정되지 않은 항목은 빈 상태로 남깁니다. CSV와 그림은 같은 분석의 두 형식입니다.

    자료를 연결하는 순서

    1. 공식 원본 CSV와 취득 조건을 보존합니다.
    2. manifest에 경로·SHA-256·출처·취득 시각·스냅숏을 기록합니다.
    3. 입력 검사를 통과한 자료로 연구 CLI를 실행합니다.
    4. 새 결과 폴더를 선택해 이 읽기 전용 화면을 시작합니다.

    화면에서 수집·학습을 실행하지 않습니다. 실행 명령과 입력 양식은 차수 폴더의 사용 안내에 있습니다.
