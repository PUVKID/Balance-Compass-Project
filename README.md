# Balance Compass

[한국어](#) · [English](en/README.md)

전국 아파트 전세 보증금·월임대료 예측과 예측구간 신뢰성을 연구한다. 현재 새 연구 10차는 외부 특징 식별키·생성 열과 위치 연산의 행 경계를 검증한다. 기존 8개 가설 · 15개 평가는 보존한다.

기존 모델·확장 비교는 4차 안내, 새 취득·감사는 5차 안내를 따른다. 학교 12,004·공원 18,376·철도역 898행은 현재 자료 취득 상태이며 계약 결합은 미완이다. 단지식별 파일은 공시 행 수와 달라 격리했다. 엄격한 과거 시점 재현과 대규모 학습은 미완이다. 실제 원자료·모델·실험 결과·인증자료·개인 운영 기록은 공개하지 않는다. 시간·지역 이동의 포함률 보장, 대규모 실측 완료 성능, 신규 지표의 검증 성과를 주장하지 않는다. 과거 클라우드 V10과 새 연구 번호는 별개다.
