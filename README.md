# Balance Compass

전국 아파트 임대료 예측과 예측구간 신뢰성 연구 도구다. 새 연구 2차를 Windows 로컬에서 신규 구현했다. Python 연구 파이프라인과 Rust 금액 정규화, 읽기 전용 대시보드를 연결한다.

**전국 실측 자료는 미확보이며 전국 본실험은 미실행이다.** 합성 검증은 기술 확인이며 실제 예측 성능이 아니다. 과거 V10 원본 복구와 이번 신규 구현은 구분한다. 논문 원고·게재 성과는 아직 없다.
