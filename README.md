실행은 3차 폴더에서 시작한다. 실제 원자료·모델·실험 결과·인증자료·개인 운영 기록은 공개하지 않는다. 시간·지역 이동의 포함률 보장, 대규모 실측 완료 성능, 신규 지표의 검증 성과를 주장하지 않는다. 과거 클라우드 V10과 새 연구 번호는 별개다.
