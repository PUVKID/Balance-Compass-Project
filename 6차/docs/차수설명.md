## LEVEL 1 - Beginner

### 처음 읽는 연구 검토

같은 계약이 두 번 들어가면 오차가 달라지고, 자료가 없는 결과를 측정한 것처럼 보이면 논문 해석이 틀어진다. 이번에는 이런 입력과 표시 오류를 막았다. 예를 들어 서울 계약 3건을 비교하기로 했는데 2건만 내면 계산을 진행하지 않는다.

예측 원행은 계약 한 건의 식별표다. 합성은 시험용으로 만든 자료이고 실측은 실제 자료다. 기계 적격은 형식·ID·날짜 검사 통과를 뜻하며 실제 위치나 과거 운영을 입증하지 않는다.

| 항목 | 이전 취약점 | 6차 처리 |
|---|---|---|
| 예측 원행 | 중복·빈 ID와 건수 불일치가 계산에 유입 | 문자 ID 보존, 목표·분할 간 중복/건수/날짜 검사 |
| 서울 H5 | 직접 재분석에서 일부 서울 또는 다른 도시 허용 | 동일 스냅숏, 전체 서울 테스트 ID 집합 및 정답·날짜·군집 대조 |
| 자료 모드 | 알 수 없는 mode가 합성 판정 제한 우회 | REAL/SYNTHETIC만 수락, 합성 가설 지지 판정 억제 |
| 화면 수치 | 지역 합계·RMSE/MAE·구간 순서 모순 수락 | 지역 가중 일치, RMSE≥MAE, 구간·판정 상태 정합 검사 |
| 공원 ID | 충돌 ID가 하나의 시설처럼 쓰일 위험 | 충돌 원행 모두 보류, 평균·첫 행·최신 행 선택 금지 |
| 철도 | 과거 기준일과 노선 키를 현재 물리역처럼 사용 | 오래된 기준일 표시, 물리역 ID·개통 이력 미확보 차단 |
| 시설 시점 | 미래 설립·승인·불명 기준일의 과거 소급 | 시설별 행 자격 보고서 재계산 및 유효 시점 소급 금지 |
| 산출물 상태 | 전 가설 미측정인데 measured 표시 | JSON과 반환값에 동일한 unmeasured 산출물 상태 저장 |

## LEVEL 3 - Practitioner

### 재현과 오류 확인

Python 3.12, 고정 의존성, Rust 금액 파서를 준비하고 아래 검증 계약의 명령을 실행한다. 새 출력 폴더에만 시설 감사 manifest와 8개 보고서를 만든다. unittest discover는 제어 입력 145개를 검사한다. 실제 학습 명령은 실행하지 않는다.

hypothesis_results.json의 mode, input_files, hypotheses, artifacts를 확인한다. quality_reports에는 원천 ID·보고서 경로·해시를 넣어야 한다. ID/건수 오류는 예측 파일과 summary를 함께 확인하고, 시설 오류는 원문을 임의 평균하지 말고 독립 정정 근거를 확보한다.

## LEVEL 4 - Advanced

### 모듈과 실패 경계

research_metrics의 저장 결과 입구와 내부 evaluate_frames 계산을 구분했다. 시설 자격은 facility_quality에서 행 단위로 만들고 feature_store가 해시 검증 후 보고서 전체를 재계산한다. spatial_features는 신뢰된 물리 ID의 거리 수학만 담당한다.

run_dashboard는 저장 summary의 지표·지역·가설 조합을 읽을 때 검증한다. rel_tol=1e-9/abs_tol=1e-6은 표시 집계의 부동소수점 비교만 허용한다. percentile CI와 점추정치의 포함 관계를 강제하지 않는다. 서버는 루프백 읽기 전용이며 학습 제어 기능이 없다.

## LEVEL 5 - Expert

### 추론 조건과 실제 검토 범위

기존 15개 목표별 family, 예측구간 alpha=.1, 가설 family confidence=.95, bootstrap=9,999와 고정 서울 H5를 유지한다. full Seoul ID 집합 및 paired 정답·날짜·지역·군집을 검사해 사후 부분표본 비교를 막는다. Σn_g=n 및 Σn_g MAE_g/n=MAE, RMSE≥MAE가 표시 정합 조건이다.

신뢰구간은 학습된 모델 조건부 군집 bootstrap 근사이며 시간 이동·군집 의존·작은 표본에서 보장을 주장하지 않는다. 시설 보고서는 진실성·완전성 검증을 대신하지 않으며 역사를 입증하지 못한다. 새 가설·효과 문턱·통계량·문헌 인용을 추가하지 않았다. 기존 수식과 인용 원문은 연결 문서에 보존했다.
