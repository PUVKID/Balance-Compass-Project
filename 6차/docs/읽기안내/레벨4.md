### 모듈과 실패 경계

research_metrics의 저장 결과 입구와 내부 evaluate_frames 계산을 구분했다. 시설 자격은 facility_quality에서 행 단위로 만들고 feature_store가 해시 검증 후 보고서 전체를 재계산한다. spatial_features는 신뢰된 물리 ID의 거리 수학만 담당한다.

run_dashboard는 저장 summary의 지표·지역·가설 조합을 읽을 때 검증한다. rel_tol=1e-9/abs_tol=1e-6은 표시 집계의 부동소수점 비교만 허용한다. percentile CI와 점추정치의 포함 관계를 강제하지 않는다. 서버는 루프백 읽기 전용이며 학습 제어 기능이 없다.

| 모듈 경계 | 현재 계약 | 검토할 실패 |
|---|---|---|
| research_metrics | 저장 입력 검증 뒤 evaluate_frames 계산 | 원행·목표·분할·mode·전체 서울 집합 불일치 |
| run_dashboard | 지역 n 가중 집계, RMSE≥MAE, 상태·판정·CI 검증 | rel_tol=1e-9/abs_tol=1e-6은 표시 오차 허용만 의미 |
| facility_quality → feature_store | 행별 사유와 원천/보고서 SHA 대조·전체 재계산 | source/feature 종류·날짜 정책·보고서 위조 거부 |
| spatial_features | 검증한 물리 ID로 거리 계산 | 노선별 역번호·공원 충돌 ID를 물리 ID로 추정 금지 |
