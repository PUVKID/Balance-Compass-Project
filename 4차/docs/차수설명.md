## LEVEL 1 - Beginner

자료를 받았다는 사실과 예측을 잘한다는 결과를 구분한다. 이번 차수는 자료를 보존하고 실제 출처를 확인하는 준비 코드다. 평균 금액 오차와 예측 범위 포함률은 실제 학습 후에만 보고하며 지금은 성능 수치가 없다.

| 먼저 볼 내용 | 쉬운 설명 | 지금의 상태 |
|---|---|---|
| 자료 보관 | 계약서 목록의 원래 21개 항목을 보관합니다. | 수집 규모와 실제 학습 표본 수는 다릅니다. |
| 주변 시설 | 학교·공원·역 자료를 받았습니다. | 각 계약과 연결하는 작업은 미완료입니다. |
| 예측 결과 | 금액 오차와 예측 범위를 함께 확인합니다. | **실제 학습 중지 · 성능 미산출** |

<a id="reading-level-2"></a>
## LEVEL 2 - Explorer

48개월 · 4,845,086행의 21개 원문 항목을 새 입력에 보존했다. 원문을 고치지 않고 SHA와 행 수로 추적한다. 학교·공원·철도역은 현재 자료이며 단지 좌표 연결과 과거 운영 이력은 아직 없다. 공원 좌표 이상 1행과 단지 파일 행 수 불일치는 원본과 분리해 기록한다.

| 처리 단계 | 연결되는 정보 | 구분할 점 |
|---|---|---|
| 원문 → 연구 입력 | 출처·SHA·행 수와 추적 키 | 원문은 수정하지 않습니다. |
| 시설 → 특징 | 현재 시설 목록과 단지 좌표 | 과거 운영 이력과 계약 연결은 별도 검증입니다. |
| 입력 → 비교 | 같은 계약의 전체 정보와 정보군 제거 | 후보 62개를 모두 확보한 것은 아닙니다. |

<a id="reading-level-3"></a>
## LEVEL 3 - Practitioner

실행 안내의 공개자료 취득·입력 추출·특징 검증을 순서대로 사용한다. 기존 출력은 덮어쓰지 않는다. expansion CLI는 기본 계획만 출력하며 --execute가 있어야 적합한다. 현재는 대규모 학습 중지 상태다. 특징 원천이 없거나 정답 공개 이력이 없는 엄격 모드는 준비 완료로 판정하지 않는다.

| 실행 전 확인 | 확인 방법 | 미충족 시 동작 |
|---|---|---|
| 원본 입력 | SHA·행 수·21열과 추적 키를 대조합니다. | 잘못된 입력을 조용히 사용하지 않습니다. |
| 특징 명세 | 결합 키·출처·유효기간·공표 시각을 검증합니다. | 특징 누락과 정답 이력 미검증은 엄격 실행을 차단합니다. |
| 실행 권한 | 계획을 검토하고 `--execute`를 명시합니다. | 기본 명령은 계획만 출력하며 학습은 중지 상태입니다. |

<a id="reading-level-4"></a>
## LEVEL 4 - Advanced

Ridge/HGB의 전체 정보 검증 MAE로 알고리즘을 선택하고 기본/정보군 제거는 같은 알고리즘으로 고정한다. 같은 계약의 절대오차 차이·상대개선율·월/지역/매칭별 지표를 저장한다. 결측 대체와 범주는 학습에서 적합한다. 보증금제외 비교에서도 나머지 확장 입력을 유지한다. 가격집계의 홀드아웃 파생집합 추적은 미구현이므로 해당 경로를 차단한다.

| 구현 경계 | 처리 방식 | 설계상 제한 |
|---|---|---|
| 특징 저장소 | 계약 원행을 유지하고 최신 적격 관측 하나를 결합합니다. | 모호한 관측은 오류로 처리합니다. |
| 알고리즘 선택 | 전체 정보의 검증 MAE로 Ridge/HGB를 선택합니다. | 정보군 제거 비교에도 같은 알고리즘을 고정합니다. |
| 전처리·분할 | 대체 값과 범주를 학습 자료에서 적합합니다. | 가격 집계의 홀드아웃 계보가 없는 경로는 차단합니다. |

[같은 수준 안내](읽기안내/레벨4.md) · [확장 실행](4차_실행안내.md)

<a id="reading-level-5"></a>
## LEVEL 5 - Expert

유효기간[from,to)와 계약일 KST 00시 이전 published_at을 모두 만족하는 최신 단일 관측만 엄격 결합한다. 학습·보정 정답의 당시 공개 이력은 별도 요구하며 현재 실행기는 이를 미검증으로 거부한다. 탐색적 평균 절대오차 차이에 단지 군집 부트스트랩 9,999회 percentile 방식의 95% 근사 구간을 적용한다. 군집 미상 또는 20개 미만은 구간 미산출이다. 기존 15개 검정 가족 확인적 추론과 혼합하지 않으며 시공간 공통 충격·모델 적합 불확실성은 모두 해결하지 않는다.

| 검토할 추론 조건 | 구현·평가 기준 | 해석 한계 |
|---|---|---|
| 시점 적격성 | 유효기간 `[from, to)`와 계약일 KST 00시 이전 공표 | 관측 시점 검사만으로 과거 원천·정답 이력이 입증되지는 않습니다. |
| 비교 단위 | 같은 계약의 절대오차 차이·단지 군집 재표집 | 군집 미상 또는 20개 미만은 구간을 산출하지 않습니다. |
| 불확실성 | 9,999회 percentile 방식의 95% 근사 구간 | 탐색적 구간이며 기존 15개 검정 가족·시공간 충격·모델 적합 불확실성을 대체하지 않습니다. |
