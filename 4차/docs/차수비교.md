# 3차 → 4차 비교

| 범위 | 3차 | 4차 |
|---|---|---|
| 원문 입력 | 9열 선택 입력 | 21열 전체 보존+원행/단지 추적키, 해시·행 수 전수 대조 |
| 공식 외부자료 | 후보 조사 | 학교 12,004·공원 18,376·역 898행 현재 자료 취득, 단지 식별 307,834행 격리 |
| 시간 자격 | 날짜 분할 | 유효기간·시간대 포함 공표 시각·당일제외 결합, 정답 이력 없는 엄격 실행 차단 |
| 비교 | 8개 가설 · 15개 평가 유지 | 같은 계약·고정 알고리즘의 정보군 제거, 별도 탐색적 구간 |
| 오류 검사 | 기존 81개 | 신규 19개 포함 100개, 합성 기술검사만 수행 |
| 미완료 | 실제 학습 중지 | 외부 연결·과거 이력·시장통계·동결/자원 검사 남음 |

실제 추가·수정·삭제 전체는 [전체 차이](전체차이.diff)를 확인한다. 이전 3차 구현은 보존한다. 현재 자료의 과거 사용 가능성을 단정하거나 외부 연결이 완료됐다고 주장하지 않는다.

4차 배포에는 중복 history 사본을 포함하지 않는다. 이전 1~3차의 공개 파일은 저장소에 그대로 보존하며 삭제 커밋은 없다. 전체 비교는 이 패키지 구성 차이도 표시한다.
