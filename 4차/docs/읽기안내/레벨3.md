**실제 학습 중지·성능 미산출**

실행 안내의 공개자료 취득·입력 추출·특징 검증을 순서대로 사용한다. 기존 출력은 덮어쓰지 않는다. expansion CLI는 기본 계획만 출력하며 --execute가 있어야 적합한다. 현재는 대규모 학습 중지 상태다. 특징원천이 없거나 정답공개이력이 없는 엄격모드는 준비완료로 판정하지 않는다.

| 실행 단계 | 도구 | 실패 시 동작 |
|---|---|---|
| 원문 변환 | research_input --root --output | 해시·월·행수 다르면 중단 |
| 공개 취득 | public_sources --id --output | 인증 요구·내용 오류면 중단/격리 |
| 특징 검증 | validate_feature_manifest | 원천SHA·행수·취득시각 오류 거부 |
| 비교 계획 | expansion --manifest --features --output | --execute 없으면 계획만 출력 |
