**실제 학습 중지·성능 미산출**

Ridge/HGB의 전체정보 검증 MAE로 알고리즘을 선택하고 기본/정보군제거는 같은 알고리즘으로 고정한다. 같은 계약의 절대오차 차이·상대개선율·월/지역/매칭별 지표를 저장한다. 결측 대체와 범주는 학습에서 적합한다. 보증금제외 비교에서도 나머지 확장 입력을 유지한다. 가격집계의 홀드아웃 파생집합 추적은 미구현이므로 해당 경로를 차단한다.

| 모델 단계 | 고정/선택 규칙 | 검증 지점 |
|---|---|---|
| 학습 | Ridge/HGB, 학습에서만 대체·인코딩 | 검증·테스트 정보로 전처리 적합 금지 |
| 선택 | 전체정보 검증 MAE 최소 | 테스트 선택 금지 |
| 정보군 제거 | 같은 알고리즘·같은 테스트 계약 | 원행ID 일치·특징 목록 기록 |
| 월세 보증금 제거 | 나머지 확장입력 유지 | 보증금만 제거한 별도 AI 비교 |
