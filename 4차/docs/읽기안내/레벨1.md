**실제 학습 중지·성능 미산출**

자료를 받았다는 사실과 예측을 잘한다는 결과를 구분한다. 이번 차수는 자료를 보존하고 실제 출처를 확인하는 준비 코드다. 평균 금액오차와 예측범위 포함률은 실제 학습 후에만 보고하며 지금은 성능 수치가 없다.

| 보는 수치 | 의미 | 지금 상태 |
|---|---|---|
| 평균 금액오차 | 예측과 실제값 차이의 평균 | 실측 미산출 |
| 90% 예측범위 | 실제값이 범위에 들어온 비율도 확인 | 보장된 성공률 아님 |
| 외부자료 | 학교·공원·역의 현재 위치자료 | 과거 계약과 결합 미완료 |
| 논문 결론 | 실제 결과로 가설을 판단 | 아직 작성 가능한 성과 없음 |
