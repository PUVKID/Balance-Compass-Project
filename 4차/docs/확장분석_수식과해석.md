# 확장 분석 수식과 해석

이 문서는 연구방법 명세이며 완성 논문 원고나 실측 결과가 아니다. 기존8개 가설·15개 평가·인용은 [가설 수식](논문_가설과_수식.md)을 따른다.

| 계산 | 정의 | 출처와 지위 |
|---|---|---|
| 동일 계약 오차 차이 | d_i=abs(y_i-p_basic,i)-abs(y_i-p_full,i); Delta=sum(d_i)/n | 직접 정의한 단순 비교 효과량. 양수는 전체 정보 MAE가 낮음 |
| 상대 개선율 | 100 Delta / MAE_basic | 분모0이면 미산출. 새 통계이론 아님 |
| 군집 재표집 | 단지g별 S_g=sum(d_i), n_g; 단지K개를 복원추출해 Delta*=sum S_g*/sum n_g* | 기존 군집 부트스트랩 원리를 평균차이에 적용. 9,999회, seed20261126, 2.5/97.5 분위수 |
| 거리 | d=2R asin(sqrt(sin²((phi2-phi1)/2)+cos(phi1)cos(phi2)sin²((lambda2-lambda1)/2))) | haversine 구면 직선거리. BallTree(metric=haversine), 각도는 라디안 |
| 반경별 역수 | N_r(i)=서로 다른 검증된 물리역ID 중 d(i,s)<=r 개수 | r=500/1000m. 노선별 원행을 역개수로 중복 계산하지 않음 |
| 반경별 노선수 | L_1000(i)=반경 안 역의 서로 다른 노선ID 수 | 미상 노선을0으로 쓰지 않음. 원자료명칭을 공통ID로 만드는 감사 필요 |
| 시점 자격 | valid_from<=t<valid_to AND published_at<contract_day_start_KST | 직접 정한 보수적 입력 자격. 엄격 모드 정답 이력까지 자동 인증하는 식은 아님 |

거리의 R=6371008.8m는 구면 근사에 사용하는 고정 상수다. 정밀 측량·도로/도보거리로 해석하지 않는다. 단지/시설 좌표 측정오차와 운영 이력이 별도 제한이다. 한국 범위32..39.5도/124..132도 검사는 넉넉한 이상치 탐지이고 국경·행정경계 판정이 아니다.

탐색적 CI는 여러 비교의 동시 포함률을 보장하지 않고 시간·지역 공통 충격과 모델 적합 불확실성을 모두 반영하지 않는다. 군집≥20은 이 연구의 최소 계산 규칙이며 충분한 정확성을 보장하는 정리가 아니다. 기존 15개 검정 가족 확인적 구간과 혼합하지 않는다.

- [scikit-learn DistanceMetric 공식 문서](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.DistanceMetric.html): haversine 거리와 라디안 좌표.
- [Cameron et al. 군집 부트스트랩 논문](https://www.nber.org/papers/t0344): 군집 의존성 고려의 배경. 논문의 bootstrap-t를 그대로 구현한 것이 아님.
- [공식 학교 자료](https://www.data.go.kr/data/15021148/standard.do), [공원 자료](https://www.data.go.kr/data/15012890/standard.do), [역 자료](https://www.data.go.kr/data/15013205/standard.do): 현재 위치 자료의 원천. 취득/과거자격/결합은 구분.
