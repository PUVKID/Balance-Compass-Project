# 사전 분석 계획: 8개 가설과 자동 계산

분석계획 버전: 3차 / 2026-11-26. 실제 학습을 중지한 상태에서 정의했다. 실제 학습 완료 수치·가설 지지 결과는 아직 없다. 이 문서는 방법 명세이며 투고 원고나 게재 논문이 아니다. 이후 변경은 이유와 시점을 별도 버전으로 기록한다.

## 자료와 분석 단위

확보한 공개 스냅숏은 2022-01~2025-12 전국 아파트 전월세 48개월, 원문 4,845,086행이다. 이는 정제 후 학습 행 수가 아니다. 신규계약 주분석에서 제외되는 행·구분 불명·취소 관측 여부를 따로 보고한다. 역사적 행정구역 동등성·임차가구 모집단 완전성은 확인하지 않았다. 동일 원문 행도 별개 신고일 수 있어 무조건 삭제하지 않는다.

| 분할 | 계약일 | 사용 목적 |
|---|---|---|
| 학습 T | 2022–2023 | 전처리·모델 적합·가격 경계·척도 |
| 검증 V | 2024 상반기 | 각 후보군의 MAE 최소 모델 선택 |
| 보정 C | 2024 하반기 | 선택 모델의 절대 잔차로 예측구간 보정 |
| 테스트 E | 2025 | 사전 고정한 가설의 최종 평가 |

전세 보증금과 월임대료는 별도 목표다. 금액 단위는 원, 포함률은 0~1 비율이다. MAE=Σ|yᵢ−ŷᵢ|/N, RMSE=√(Σ(yᵢ−ŷᵢ)²/N). 월세에는 계약 시 관측한 보증금을 특징으로 쓴다. 모델 후보는 전체 중앙값·지역 중앙값·Ridge·HistGradientBoosting이다. AI A는 Ridge/부스팅 중 검증 MAE로, 기준 B는 두 중앙값 중 검증 MAE로 고른다. 기본 보고용 선택 모델 S는 전체 후보 중 검증 MAE로 고른다. 동률 규칙은 엔진 구현을 따른다. 테스트로 선택하지 않는다. 부스팅은 고정 80회, early_stopping=False다.

단지 군집은 원문 시군구·지번·단지명으로 만든 안정된 해시다. 행 식별자는 원본 파일 해시와 행 위치에서 만든다. 실제 개인·세대·법적 계약 식별자가 아니며 명칭 변화·다중 단지·군집 간 의존을 해결하지 못한다. 기존 9열 자료에는 이 키가 없어 새 출력에 로컬 변환을 거쳐 추가해야 한다. 원본·기존 결과는 보존한다.

## 예측구간과 점수

α=0.10. 보정 오차 rⱼ=|yⱼ−ŷⱼˢ|, m=|C|, k=⌈(m+1)(1−α)⌉, q=r₍ₖ₎. 구간은 Lᵢ=ŷᵢˢ−q, Uᵢ=ŷᵢˢ+q다. k>m이면 구간 미산출이다. 음수 하한을 임의 절단하지 않는다. 이 순위는 Lei 등(2018)의 split conformal에 따른다. 교환가능성 등의 조건에서 주변적 포함률을 다루는 방법이며, 시간·지역 이동에서 본 데이터의 90% 포함률을 보장하지 않는다.

cᵢ=1{Lᵢ≤yᵢ≤Uᵢ}, p=Σcᵢ/N. 지역 g의 p_g는 같은 식을 그 지역에 적용한다. G는 테스트에서 N_g≥30, 관측 단지 K_g≥5를 충족하는 고정 지역 집합이다. 지역 동일 가중 편차 D=|G|⁻¹Σ_g|p_g−0.90|. 적격 집합은 최초 표본에서 고정하고 부트스트랩마다 다시 선택하지 않는다.

Gneiting·Raftery(2007) §6.2 식(43)의 interval score를 적용한다:

ISᵅ(L,U;y)=(U−L)+(2/α)(L−y)1{y<L}+(2/α)(y−U)1{y>U}.

평균 구간 점수 MIS=ΣISᵅ/N. 폭과 미포함 벌점을 함께 보며 낮을수록 좋다. 포함률만 높여 매우 넓은 구간을 만드는 경우를 함께 드러낸다.

## 고정 가설과 효과량

ε=0.02(2%p)로 정한다. 이는 실험 결과에서 최적화한 값이 아닌 본 연구의 실무적 허용오차 제안이다. H2는 월세만, 나머지는 두 목표에 적용해 총 15개 평가를 같은 가족으로 묶는다.

| 가설 | 사전 기대와 효과량 θ | 단위·해석 |
|---|---|---|
| H1 | θ₁=MAE(B)−MAE(A)>0 | 원. AI의 미래 계약 오차가 검증 선택 중앙값 기준보다 작은가 |
| H2 | θ₂=MAE(A_without_deposit)−MAE(A_with_deposit)>0 | 원. 각 특징 집합에서 별도로 검증 선택한 AI 파이프라인 비교. 보증금의 인과효과 아님 |
| H3 | θ₃=p−0.90 ∈(−ε,+ε) | 비율. 전체 포함률의 동등성. 90%와 유의하게 다르지 않음만으로 동등 판정하지 않음 |
| H4 | θ₄=D−ε>0 | 비율. 지역 동일 가중 포함률 편차가 허용오차보다 큰가. 지역 간 이질성 자체를 검정하는 식은 아님 |
| H5 | θ₅=mean_i∈서울(|yᵢ−ŷᵢˢ,held|−|yᵢ−ŷᵢˢ,seen|)>0 | 원. 같은 서울 테스트 계약에 대한 지역 제외·일반 실행의 선택 파이프라인 오차 차이 |
| H6 | θ₆=(MAE(S;high)−MAE(S;low))/s_T>0 | 무차원. 학습 목표값의 20·80 분위 경계로 테스트 실제 y를 분류. 사후 진단이며 배포 전 가격대 분류 성능이 아님 |
| H7 | θ₇=D_global−D_regional>0 | 비율. 같은 적격 지역에서 지역 보정 정책이 편차를 줄이는가 |
| H8 | θ₈=mean_g∈G_time(p_g,1–6월−p_g,7–12월)>0 | 비율. 지역 구성을 맞춘 하반기 포함률 감소. 원인·추세 일반화 아님 |

H5는 서울특별시를 학습·검증·보정에서 모두 제외한 추가 실행을 한다. 원본 SHA·행·정답·날짜·지역·단지 키를 대조하고 일반 실행의 서울 행 집합과 정확히 같아야 한다. 두 실행은 동일 3차 코드·분할·후보 설정을 사용하되, 지역 배제로 선택된 모델은 달라질 수 있다. 따라서 순수한 동일 모델의 인과 효과가 아닌 파이프라인 이동 진단이다. 두 실행이 없으면 null/미산출이다.

H6에서 low는 y≤학습 20분위 경계, high는 y>학습 80분위 경계다. s_T=학습 목표값 중앙값>0. 양쪽 각각 최소 20개 관측 단지가 있어야 확정 판정을 시도한다. 중복 제거 전 원시 분위수(train_price_quantiles_won)를 사용한다. 기존 unique 경계가 6개 미만이면 원래 20·80분위를 복원할 수 없어 미산출이다. 경계가 겹치거나 척도가 유효하지 않으면 미산출이다. H8은 양 반기 각각 지역 내 N≥30·K≥5인 동일 지역만 사용한다.

H7의 지역 반경 q_g는 2024 하반기 해당 지역 보정 표본이 100개 이상일 때 같은 순위식으로 계산한다. 부족 지역은 q로 대체한다. 적격 테스트 지역에 실제 지역 보정이 적용된 지역이 0이면 H7은 미산출이다. 실제 보정 지역 수와 대체 행 수·비율을 저장한다. Vovk(2012)의 그룹 조건부 접근을 참고했으나 시간 교환가능성이나 소표본 그룹 보장을 주장하지 않는다.

## 불확실성과 판정 규칙

관측 단지 K≥20일 때 단지 단위 재표집 9,999회, 고정 seed=20261126을 사용한다. H1/H2/H3/H6는 전체 단지를 재표집하고 같은 계약의 비교 손실은 함께 재표집한다. H4/H7/H8은 적격 지역마다 해당 지역 안의 단지를 재표집한다. H5는 같은 계약의 두 손실 차이를 서울 단지별로 묶어 재표집한다. 단지 안 계약 행 전체를 함께 취급한다. Cameron 등(2008)은 군집 의존성 고려의 참고이며 해당 논문의 bootstrap-t 개선 알고리즘을 구현했다는 뜻은 아니다.

15개 평가의 명목 가족오류율을 0.05로 두고 각 percentile 구간 양 끝 확률을 0.05/(2×15), 1−0.05/(2×15)로 정한다. 개별 명목 신뢰수준은 약 99.6667%다. 이는 근사 부트스트랩 구간에 Bonferroni 원칙을 적용한 것으로 가족 95%의 정확한 유한표본 보장을 주장하지 않는다. p값은 산출하지 않는다. 유효한 재표집이 요청 반복수의 80% 미만이면 구간을 비운다. 요청·유효 반복수를 함께 기록한다.

| 조건 | 판정 |
|---|---|
| H1/H2/H4/H5/H6/H7/H8 구간 하한>0 | support(가설 지지) |
| 위 가설 구간 상한≤0 | not_support(기대 방향 지지 안 됨) |
| H3 구간 전체가 (−.02,+.02) 안 | support |
| H3 구간 전체가 허용 범위의 한쪽 바깥 | not_support |
| 나머지·표본 부족·축소 반복 기술 검사 | inconclusive 또는 unmeasured |

학습된 모델과 고정 보정 반경을 조건으로 테스트 군집의 불확실성을 근사한다. 모델 재학습·보정 표본 불확실성·단지 간 공간 의존·신고 지연·지역 경계 변화까지 포함한 불확실성이 아니다. 확정 지지가 사실의 증명이나 인과관계는 아니다. 합성 검사에서는 지지 판정을 강제로 막는다.

## 본 연구용 제안 요약지표

정확도·구간 점수·지역 편차를 함께 요약하는 다음 식을 미리 제안한다:

BC_loss=0.50×MAE(S)/s_T + 0.25×MIS(S)/s_T + 0.25×D/α.

세 항은 무차원이며 낮을수록 작다. 가중치 (.50,.25,.25)를 고정하고 (.25,.50,.25), (.25,.25,.50) 민감도 값도 함께 저장한다. 기존 MAE·interval score·지역 편차를 조합한 **검증 전 연구용 제안**이다. 새로운 검증된 통계량·proper score·선행연구에 없는 독창적 수식이라고 주장하지 않는다. 모델 선택·8개 가설 지지 판정에는 사용하지 않는다. 구성 성분을 항상 함께 보고해야 한다.

## 자동 실행과 재현 산출물

`rentlab.engine.run`은 예측·보정 CSV를 저장한 다음 `write_research_results`를 자동 호출한다. 추가 지역 실행은 `rentlab.experiment_runner --with-holdout 서울특별시`로 계획하며 `--execute`를 주어야 학습한다. H5 통합은 두 실행 결과의 실제 복사본을 새 폴더에 만들어 검증한 뒤 수행한다. 저수준 `evaluate_frames`는 신뢰된 내부 프레임용이며 외부 결과를 논문에 사용할 때는 메타·출처 검증이 있는 상위 실행 경로를 사용한다.

| 산출물 | 내용 |
|---|---|
| hypothesis_results.json | 15개 평가의 효과·구간·판정·이유·단지 수·유효 반복수·설정·출처·분석 코드 SHA |
| hypothesis_results.csv | 같은 가설 행을 표로 저장; 없는 값은 빈칸 |
| *_predictions.csv | 같은 계약 비교용 행·단지 키와 후보별 예측값 |
| *_calibration_predictions.csv | 고정 반경을 재계산할 보정 예측값 |
| summary.json | 실행 모드·모델·분할·입력 해시·제약·가설 결과 |

정수 금액 정규화 후 회귀·점수에는 부동소수 계산을 사용한다. 출력 자리수가 실제 측정 정밀도를 보장하지 않는다. 결측 결과를 0으로 채우지 않으며 실패·부분 산출을 숨기지 않는다.
