## 전문 검토의 판정 경계

이 차수는 자료 취득·보수적 결합·현재 좌표의 재현 가능한 기술 검증이다. feature_ready=false와 historical_availability_proven=false를 유지한다. 인구 증가율은 자격 감사만 있고 실제 특징값 파일은 없으며, 확대 특징을 기존 8가설 15평가에 통합하지 않았다. **정제 전 신규 분모와 최종 모델 표본을 분리한다.**

검사 120개는 기존 모델 합성 기술검사와 새 파서·주소·좌표 회귀검사의 합계다. 독립 검토에서 네 P2 경계 오류를 재현·수정했고, 실제 MOIS 6원본/KAPT/BOK 재파싱과 좌표 변환 결과를 대조했다. 기술 PASS를 과거 정보의 사실성·표본 대표성·실측 예측 성과로 확대하지 않는다.

| 추론 계층 | 현재 구현/근거 | 확정하지 못한 점 |
|---|---|---|
| 기본 8가설 15목표 평가 | 기존 예측 결과에 사전 식 적용 | 실제 대규모 적합 결과 없음 |
| 확대 정보 비교 | 동일 계약의 MAE 차이·정보군 제거 | 특징 스냅샷과 전체 실험 행렬 미동결 |
| 불확실성 | 기존 군집 부트스트랩·다중평가 조건 보존 | 시간/지역 이동의 정확 포함 보장 없음 |
| 원천 시간 | 대상 월·결정일·이번 취득 시각 | 당시 발표 원본·정답 공개 및 수정 빈티지 없음 |

기존 확증 경로는 9999회 단지 군집 부트스트랩과 15평가 Bonferroni 근사 구간을 사용하며 정확한 동시 95% 보장이라고 해석하지 않는다. 확대 정보군 비교의 점별 95% 군집 근사 구간은 별도 탐색 결과다. 제안 복합손실 BC_loss는 검증되지 않은 보조 지표이고 적정점수·선택 기준·새 정리로 주장하지 않는다. 기존 가설·인용 문서의 범위를 유지한다.


실제 학습은 중지 상태다. 이번 차수는 공식 자료 취득·정규화·연결 감사이며, 예측 성능이나 가설 지지 결과가 아니다. 원본과 이전 차수는 보존한다.

인구 자료는 현재 서비스가 제공하는 과거 수치다. 당시 내려받은 원본이나 수정 빈티지 이력은 확보하지 않았다. 지역 코드·명칭 변화, 폐지 지역의 0값과 공란을 서로 구분한다. 20,088행 정상, 348행 원천 공란, 720행 인구·세대 모두 0인 원천 행이다. 중첩 행 전체를 더해 전국 인구로 사용하지 않는다.

## 실제 연결 감사

| 원문 신규 계약 연도 | 분모 | 인구 시군구 수준 연결 | 시도 수준 대체 연결 | 미연결 | 동일 지명 복수 계층 | KAPT 이름·지번·도로명 연결 |
|---|---:|---:|---:|---:|---:|---:|
| 2022 | 606,292 | 521,922 | 15,214 | 56,187 | 12,969 | 86,906 |
| 2023 | 732,312 | 650,805 | 17,470 | 51,906 | 12,131 | 101,347 |
| 2024 | 789,728 | 721,889 | 14,716 | 39,163 | 13,960 | 105,002 |
| 2025 | 751,948 | 685,298 | 14,274 | 38,870 | 13,506 | 94,734 |
| 합계 | 2,880,280 | 2,579,914 | 61,674 | 186,126 | 52,566 | 387,989 |

인구는 계약월에서 2개월을 뺀 월의 이름을 토큰 경계에 맞춰 연결했다. 같은 지명의 서로 다른 행정 계층은 자동 선택하지 않는다. 세종의 두 코드처럼 인구가 같아도 임의 합치지 않는다. 명칭이 달라진 지역도 자동 교정하지 않는다. 이것은 연결 자격 감사이며 최종 정제 표본의 매칭률이 아니다.

기준금리는 결정일이 계약일보다 앞선 값만 사용하도록 시험했다. 신규 계약 2,880,280행 모두 날짜상 과거 결정값이 존재했다. 이 값이 예측 성능을 높인다는 뜻은 아니다.

KAPT는 법정동주소 끝의 단지명을 정확히 분리하고 지번·단지명이 일치한 후보에서 도로명까지 확인했다. 3,162개 고유 단지 코드, 계약 387,989행(원문 신규의 약 13.47%)이 연결됐다. 동일 cluster_id가 서로 다른 KAPT 코드로 연결된 경우는 관측되지 않았다. 별칭·번지 말미 하이픈·행정구역 개편 등을 임의 정규화하지 않아 연결률이 낮다. 이 부분집합을 전국 대표 표본으로 주장할 수 없다. 표본 수작업 대조와 미연결 편향 평가가 남아 있다.

## 좌표 처리

| 검증 상태 | 단지 코드 수 | 처리 |
|---|---:|---|
| 유일하고 유효한 현재 지도점 | 21,207 | 현재 좌표 후보로 보존 |
| 서로 다른 좌표 충돌 | 1,320 | 대표점·평균점 선택 없이 격리 |
| 일부 또는 전체 좌표 누락 | 95 | 결측 보존 |
| 잘못된 수치 또는 원점 0,0 | 19 | 격리 |

일부 코드에는 좌표 누락과 충돌이 함께 있다. 표는 잘못된 수치→누락→충돌의 우선순위로 나눈 배타적 상태이며, 원좌표 쌍이 둘 이상인 전체 코드 수와 구분한다. 이 지도점이 단지 중심점·출입구·측량점인지는 증명되지 않았다. 실제 보행거리나 과거 개교·개통·시설 운영 상태로 해석하지 않는다.

공식 `knew_map.js`의 중앙원점 TM PROJ 문자열 전체를 그대로 보존하고 WGS84 경위도로 변환한다. 소스 주석의 EPSG 번호를 추측해 적용하지 않는다. pyproj 3.7.2 `Transformer.from_crs(..., always_xy=True)`로 경도·위도 순서를 고정한다. [공식 pyproj 문서](https://pyproj4.github.io/pyproj/stable/api/transformer.html)의 축 순서 조건을 따른다. 소수 자릿수는 실제 위치 정확도를 의미하지 않는다.

## 사전 수식과 사용 자격

| 수치 | 식 | 조건 |
|---|---|---|
| 인구 지연값 | P*(i,t) = P(g(i), month(t)-2) | 정확한 이름 연결. 2개월 지연은 연구상 가정이며 실제 공표 시각으로 저장하지 않음 |
| 인구 전년동월 증가율 후보 | 100 × [P(g,m)/P(g,m-12)-1] | 같은 코드, 두 시점 정상, 이전 인구>0. 개편된 코드의 전신을 추측하지 않음 |
| 세대당 주차 | 주차대수/세대수 | 세대 수>0. 현재 추출값에만 해석 가능 |
| 세대당 승강기 | 6종 승강기 합계/세대수 | 한 종류라도 미입력이면 결측. 0을 임의 대입하지 않음 |
| 기준금리 연결 | r(t)=r(s*), s*=max{s:s<t} | 계약일 당일 결정 제외. 관측된 발표 시각 증명은 별개 |

단지 자료 21,805행 중 유효한 세대 수 분모는 21,793행이고 12행은 사용 불가다. 분모가 유효한 행에서도 승강기 비율 495행, 최고층 30행, 동수 15행은 결측이다. 비정상값을 0으로 바꾸지 않는다. 인구 전년동월 식은 후보 정의이며 현재 코드는 같은 코드의 비교 가능 여부만 감사한다. 실제 증가율 특징 스냅샷은 아직 만들지 않았다.

위 식은 정의된 행정 통계의 지연·비율 계산이며 새로운 학술 정리나 검증된 신규 지표라고 주장하지 않는다. 기존 [8개 가설·15개 평가와 인용](../논문_가설과_수식.md), [확장 정보군 비교 수식](../확장분석_수식과해석.md)은 유지한다. 가설 결과는 실제 예측 후에만 산출한다.

## 재현 절차

Python 3.12에서 `requirements.txt`와 `requirements_acquire.txt`를 설치한다. 아래 명령은 취득·감사만 수행한다. 출력은 존재하지 않는 새 경로여야 한다. 기본정보 XLSX는 수정하지 않는다.

```powershell
python -m rentlab.national_sources population --year 2020 --output 새폴더/MOIS_2020
# 2021~2025도 각 연도를 별도 폴더로 취득
python -m rentlab.national_sources base-rate --output 새폴더/BOK
python -m rentlab.kapt_source --output 새폴더/KAPT
python scripts/collect_kapt_map.py --search-month 202609 --output 새폴더/지도원문
python -m rentlab.kapt_coordinates --raw-root 새폴더/지도원문 --output 새폴더/좌표검증
python scripts/audit_national_sources.py --project 프로젝트루트 --output 새감사.json
python scripts/audit_complex_linkage.py --project 프로젝트루트 --output 새단지감사.json
python -m unittest discover -s tests -v
```

두 감사 스크립트는 프로젝트 내 `실제 실험/확장 입력 1차`, `외부 자료/2차/MOIS_2020`~`MOIS_2025`, `BOK`, `KAPT_검증취득` 배치를 사용한다. 새 취득 경로의 이름을 이 배치에 맞추거나 스크립트의 명시된 입력 위치를 변경해야 한다. 원응답·해시·행수·취득 시각을 보존한다. 인증키 없이 접근되는 공식 공개 절차만 사용하고 CSRF 보호를 준수한다.

## 실행 전 남은 조건

| 조건 | 현재 상태 | 다음 판단 |
|---|---|---|
| 과거 공표 원본과 수정 빈티지 | 미확보 | 엄격 과거 시점 재현은 계속 차단 |
| 주소 연결의 표본 정확도·대표성 | 자동 감사만 완료 | 수작업 대조·미연결 편향 분석 후 승인 |
| 단지–검증 좌표–시설 연결 | 원천별 검증 완료, 통합 전 | 동일 코드/단지 중복과 물리적 역 ID 확인 후 거리 산출 |

| 최종 특징 스냅샷과 비교 행렬 | 미동결 | 유효 특징과 분석 표본을 확정한 후 해시 고정 |

현재는 `feature_ready=false`, `historical_availability_proven=false`다. 자료 취득이나 테스트 통과를 연구 전체 준비 완료로 표시하지 않는다. 완성 원고·게재 성과·실측 학습 성능은 없다.
