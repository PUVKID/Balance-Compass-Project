## LEVEL 1 - Beginner

### 무엇을 연구하는가

같은 넓이의 아파트라도 지역, 건물 상태, 금리, 주변 시설에 따라 임대료가 다를 수 있다. 연구는 이런 정보를 함께 알 때 미래 계약의 전세 보증금이나 월세를 얼마나 잘 예측하는지 확인하려는 것이다. 예측 금액뿐 아니라 실제 금액을 포함하는 예측 범위도 평가한다.

**이번에 얻은 것은 연구용 자료와 검사 결과다.** 아직 모델이 새 자료로 학습하거나 미래 계약을 평가한 결과는 없다. 기존 8개 가설과 15개 목표별 평가를 유지하며, 자료가 많아졌다는 이유로 가설이 맞았다고 판정하지 않는다.

| 말 | 쉬운 뜻 | 이번 작업에서 구분할 것 |
|---|---|---|
| 계약 한 행 | 실제 신고된 계약 한 건의 기록 | 같은 아파트에서도 여러 계약이 생김 |
| 세대 수 | 지역은 주민등록 세대 수, 단지는 주거 세대 수 | 통계적 가구 수·사람 수와 구분 |
| 기준금리 | 한국은행이 결정한 정책 금리 | 그 사람이 실제 빌린 대출 금리와 다름 |
| 좌표 | 지도에서 위치를 표현하는 두 수 | 건물 출입구나 실제 걸어가는 거리가 아닐 수 있음 |
| 스냅샷 | 어느 시점에 내려받은 자료 한 묶음 | 현재 아파트 정보가 과거에도 같았다는 뜻은 아님 |
| 결측·미연결 | 값이 없거나 어느 대상인지 확정하지 못함 | 실제 값 0과 다르게 남겨야 함 |

### 무엇을 받았는가

| 자료 | 실제 확보 | 무엇에 쓸 수 있는가 |
|---|---:|---|
| 임대차 원문 | 2022–2025 4,845,086행 | 계약 날짜·금액·면적 등 기존 연구 입력 |
| 인구·세대 | 2020–2025 21,156 지역×월 | 지역 사람 수와 주민등록 세대 수의 변화 후보 |
| 기준금리 | 역사 변경 63행 | 계약 전에 결정된 정책 금리 후보 |
| 단지 기본정보 | 21,805개 | 현재 세대·동·주차·승강기 정보 후보 |
| 단지 지도 | 22,641코드 | 정상 현재 지도점 21,207개를 구분 |

입력 파일의 4,845,086행에는 갱신이나 계약 구분 미상도 있다. 이번 연결 감사의 분모는 그중 원문에 신규로 적힌 2,880,280행이다. 면적·가격·건축연도 등을 정리한 최종 실험 표본 수와는 다르다.

### 한 계약에 정보를 붙이는 과정

| 순서 | 확인하는 내용 | 확실하지 않을 때 |
|---|---|---|
| 1 | 계약 날짜와 주소를 읽음 | 원문과 출처를 남김 |
| 2 | 그 지역의 과거 월별 인구를 찾음 | 같은 이름의 두 행정 계층을 임의 선택하지 않음 |
| 3 | 계약일보다 이전에 결정된 금리를 찾음 | 계약일 당일 새 결정은 쓰지 않음 |
| 4 | 아파트 이름·지번·도로명을 함께 대조 | 이름만 비슷하면 연결하지 않음 |
| 5 | 같은 단지 코드의 지도점을 확인 | 다른 좌표가 여러 개면 대표점을 추측하지 않음 |

인구는 계약월에서 두 달 전 통계를 찾는 규칙을 시험했다. 이는 미래 자료 사용을 줄이기 위한 연구상 가정이다. 당시 실제 공개된 시각까지 확인했다는 뜻은 아니다. 예를 들어 현재 주차대수를 2022년 계약에 붙이면 2022년에도 그 주차대수였다고 단정할 수 없다.

### 계산을 어떻게 읽는가

세대당 주차는 주차대수를 세대 수로 나눈 값이다. 아파트 크기가 달라도 비교하기 위한 비율이다. 세대 수가 0이거나 없으면 계산하지 않는다. 승강기도 여섯 종류의 수가 모두 있을 때만 합산해 세대 수로 나눈다. 빠진 종류를 0으로 추측하지 않는다. 이 비율은 새 이론이 아니라 이번 연구에 사용할 변수의 정의다.

| 연결 관측 | 실제 수 | 해석 |
|---|---:|---|
| 인구 시군구 연결 | 2,579,914계약 | 해당 수준의 이름이 맞음 |
| 인구 시도 수준 대체 | 61,674계약 | 동네의 세부 정보와 구분 |
| 인구 미연결·복수 계층 | 186,126·52,566계약 | 자동 교정하지 않고 남김 |
| 단지 세 조건 일치 | 387,989계약 | 원문 신규의 약 13.47% |

단지 연결률이 낮으므로 연결된 계약만으로 전국을 대표한다고 말할 수 없다. 연결되지 않은 아파트가 더 작거나 특정 지역에 몰려 있다면 결과도 달라질 수 있다. 아직 이 편향을 검증해야 한다.

### 어디까지 확인했는가

자동검사 120개와 별도 독립 검토를 통과했다. 검사 중 발견된 잘못된 날짜·엑셀 참조·좌표 영수증 처리 오류는 실패 입력으로 재현한 후 수정했다. 이것은 코드가 확인한 조건을 지킨다는 증거이며 모든 실제 자료가 정확하거나 예측이 좋다는 보장은 아니다.

원본은 고치지 않는다. 원문 파일을 다시 읽고 같은 수치가 나오는지 대조한다. 공개 코드에는 실제 계약 원자료·모델·개인 운영 기록을 넣지 않는다.

**다음에는 단지와 검증 좌표·시설을 통합하고, 연결 정확도와 미연결 편향을 확인해야 한다.** 대출금리·물가·가격지수·미분양 등은 아직 추가 확보가 필요하다. 최종 특징과 비교 실험을 고정하고 자원을 점검한 뒤에야 큰 학습을 실행할 수 있다. 현재 학습 중지 상태를 유지한다. 완성 논문이나 게재 성과도 아직 없다.

## LEVEL 2 - Explorer

### 서로 다른 자료 단위

이번 차수는 계약·행정통계·단지·지도점의 **단위를 맞추는 준비 단계다.** 동일한 주소처럼 보인다는 이유만으로 행을 합치지 않는다. 원본과 변환본을 분리하고 어떤 원행에서 값이 나왔는지 추적한다.

| 원천 | 한 행의 단위 | 보존한 식별과 처리 |
|---|---|---|
| 임대차 원문 | 계약 한 건 | 48개월 21개 원문 항목, source_row_id·cluster_id |
| 주민등록 통계 | 지역 코드×월 | 2020–2025 21,156행, 코드·명칭·품질 상태 |
| 기준금리 | 결정일의 변경 한 건 | 63행, 연율 % 단위와 결정일 |
| KAPT 엑셀 | 단지 코드 한 개 | 21,805행, 30개 연구 열과 엑셀 원행 번호 |
| KAPT 지도 | 단지 코드의 지도점 한 개 | 24,588행을 코드별로 검사, 중복점과 충돌점 구분 |

원문 신규 계약은 2,880,280행이다. 갱신·구분 미상 등을 포함한 전체 4,845,086행이나 최종 정제 표본과 분모가 다르다. 기존 계약기간·갱신·종전 금액 같은 항목은 원문 보존 대상이며 주된 사전 예측 변수로 자동 허용하지 않는다.

### 원문에서 후보 변수까지

| 입력 | 검증 | 출력 | 아직 하지 않은 일 |
|---|---|---|---|
| 인구 연간 CSV | 12개월 열·총인구=남+여·세대 비율 | 지역×월 정규화 CSV | 과거 공표 빈티지 입증 |
| 금리 HTML | 날짜·값·중복·변경된 형식 거부 | 날짜 오름차순 변경표 | 실제 대출 금리 확보 |
| KAPT XLSX | 머리글·단지코드·참조·수식 검사 | 선택 열 CSV | 과거 시설 상태 복원 |
| 지도 JSON·공식 JS | 원응답 SHA·지역·검색월·투영 정의 | 코드별 좌표 상태 | 시설 거리와 계약의 통합 특징 |

공란은 결측이다. 0이 기록된 폐지 지역은 별도 상태다. MOIS 21,156행 가운데 정상 20,088행, 원천 공란 348행, 인구·세대 모두 0인 720행으로 나눴다. 시도 합계와 시군구·비자치구 행을 모두 더하면 중복 집계될 수 있다. 코드 변경의 전후 지역을 이름이 비슷하다고 연결하지 않는다.

### 날짜를 붙이는 방법

계약월에서 두 달을 뺀 월의 인구를 찾는다. 해당 월에 이름이 정확하게 맞는 가장 긴 지역 접두사를 사용하고, 시군구 값이 없어서 시도 값만 연결되면 이를 별도 집계한다. 세종처럼 이름은 같고 코드·행정 계층이 두 개인 경우는 모호 상태다. 인구는 시군구 2,579,914행, 시도 61,674행, 미연결 186,126행, 복수 계층 52,566행이었다.

기준금리는 결정일이 계약일보다 앞선 가장 최근 값을 찾는다. 당일 새 결정은 포함하지 않는다. 신규 계약 2,880,280행에 과거 결정값이 있었지만, 이는 날짜 연결의 포괄성일 뿐 예측 개선의 증거는 아니다.

| 시점의 종류 | 의미 | 현재 자격 |
|---|---|---|
| 통계 대상 월 | 사람이 집계된 월 | 원문에 있음 |
| 결정일·사용승인일 | 정책 결정 또는 건물 행정 날짜 | 원문에 있음 |
| 실제 발표·수정 시각 | 그 값을 예측자가 알 수 있었던 시점 | 과거 원본·빈티지 미확보 |
| 취득 시각 | 이번에 자료를 받은 시각 | 영수증에 보존 |

두 달 지연과 당일 제외는 명시한 연구 규칙이다. 이 규칙으로 실제 발표 시각을 만들어 기록하지 않는다. 엄격한 과거 시점 재현은 자료와 정답의 당시 이용 가능 이력까지 필요하므로 계속 미충족이다.

### 단지와 위치의 연결

단지명·법정동 지번이 정확히 맞는 후보에서 도로명까지 맞아야 연결한다. 전체 신규 계약 중 387,989행, 3,162개 KAPT 코드가 이 조건을 통과했다. 부분집합 비율은 약 13.47%다. 나머지 계약의 별칭·주소 표기·행정구역 변화를 자동 추정하지 않았다. cluster_id가 다른 KAPT 코드로 연결되는 충돌은 관측되지 않았지만 수작업 정답 대조는 아직이다.

| 지도 코드 상태 | 수 | 뜻 |
|---|---:|---|
| 정상 유일점 | 21,207 | 수치·변환·대한민국의 넓은 범위 검사 통과 |
| 좌표 충돌 | 1,320 | 같은 코드의 서로 다른 점, 임의 대표점 없음 |
| 누락 | 95 | 일부 또는 전체 원좌표 누락 |
| 비정상 | 19 | NaN 등 잘못된 수치 또는 0,0 |

공개 지도에 있던 16개 시도 경계를 조회했다. 과거의 17개 명칭으로 강제 변환하지 않았다. 공식 JS의 실제 PROJ 매개변수를 사용해 경도·위도로 바꿨으며 지도점의 실제 지리 정확도·출입구 여부는 별도 문제다. 현재 학교 12,004행·공원 18,376행·철도역 898행과 아직 통합하지 않았다. 공원 좌표 이상 1행과 물리적으로 같은 역의 ID 문제도 남아 있다.

### 비율과 평가의 구분

세대당 주차=주차대수/세대수, 세대당 승강기=여섯 종류 합계/세대수다. 유효한 세대 수는 21,793단지이며 12단지는 분모로 쓸 수 없다. 유효 분모에서도 승강기 비율 495행·최고층 30행·동수 15행은 결측이다. 인구 전년동월 증가율은 같은 코드 두 월의 정상값과 양의 이전 인구가 필요하다. 현재 코드는 비교 가능 여부를 감사했으며 증가율 특징 파일은 만들지 않았다.

자동 120개 검사는 원문과 수식·실패 처리의 기술 확인이다. 합성 모델 검사와 실제 자료 감사는 실측 예측 성능을 대신하지 않는다. 기존 8가설·15평가는 보존되고, 확대 정보군 비교는 별도 탐색 분석이다. 현재 특징 스냅샷 미승인·실험 미동결·학습 중지 상태이며 대출금리·물가·지수·미분양·과거 발표 이력과 자원 검증이 남아 있다.

## LEVEL 3 - Practitioner

### 준비와 디렉터리

이 차수의 명령은 취득·검증·연결 감사다. **실제 학습 재개 명령이 아니다.** Python 3.12에서 두 의존성 목록을 설치한다. `pyproj==3.7.2`는 좌표 변환에 필요하다. 원본 XLSX를 편집하거나 Excel 계산을 실행하지 않는다. 전체 기존 테스트에는 Rust 금액 CLI도 필요하다.

```powershell
python -m pip install -r requirements.txt -r requirements_acquire.txt
```

Rust 빌드 스크립트는 PowerShell에서 실행한다.

```powershell
./scripts/build_rust.ps1
```

| 위치 | 역할 | 보존 규칙 |
|---|---|---|
| `실제 실험/확장 입력 1차/자료_manifest.json` | 검증할 48개월 계약 CSV 목록 | 원행·SHA·행수 대조 |
| `외부 자료/2차/MOIS_2020`~`MOIS_2025` | 연도별 인구 원문과 정규화 | 같은 이름의 기존 폴더 덮어쓰지 않음 |
| `외부 자료/2차/BOK` | 역사 금리 변경표 | 정책 금리임을 유지 |
| `외부 자료/2차/KAPT_검증취득` | 현재 단지 XLSX·연구 열 CSV | 2026-11-20 추출본 |
| 별도 새 지도/좌표 폴더 | 현재 지도 JSON·검증 CSV | 원응답과 공식 변환 JS 보존 |

코드 저장소 폴더와 실제 자료를 보관하는 프로젝트루트는 다를 수 있다. 감사의 `--project`에는 위 자료 배치가 들어 있는 루트를 지정한다. 공개 저장소에는 실제 계약·외부 원자료가 포함되지 않는다.

### 취득 순서

아래의 `프로젝트루트`는 실제 자료 루트로 바꾼다. 모든 `--output`은 아직 존재하지 않는 새 경로여야 한다. 인구 취득의 `--year`는 2020~2025 각 연도를 한 번씩 실행한다. 2020년은 2022년 초 계약의 지연 인구를 전년동월과 비교할 가능성을 확인하기 위한 자료다.

```powershell
python -m rentlab.national_sources population --year 2020 --output "프로젝트루트/외부 자료/2차/MOIS_2020"
python -m rentlab.national_sources base-rate --output "프로젝트루트/외부 자료/2차/BOK"
python -m rentlab.kapt_source --output "프로젝트루트/외부 자료/2차/KAPT_검증취득"
python scripts/collect_kapt_map.py --search-month 202609 --output "새지도원문"
python -m rentlab.kapt_coordinates --raw-root "새지도원문" --output "새좌표검증"
```

| 단계 | 정상 확인 | 실패 시 행동 |
|---|---|---|
| 인구 | 연도별 12개월·필수 열·지역 코드 | HTML·부분 기간·인구 합계 불일치 거부 |
| 기준금리 | 63행은 이번 관측 수, 미래 실행 때 고정 기대값 아님 | 변경된 결정일 형식·중복 거부 후 원문 확인 |
| KAPT | 21,805개는 이번 현재 스냅샷 수 | 첨부 이름·형식·코드 중복 변경 시 검토 |
| 지도 | 실제 페이지의 16지역·이번 24,588행 | 지역 누락·검색월 불일치·원문 SHA 오류 거부 |
| 좌표 | 코드별 상태와 출처 JS 해시 | 충돌·누락·비정상은 격리, 대표점 생성 금지 |

KAPT 파일은 자료실의 일반 공개 세션·CSRF 토큰·첨부 목록 절차로 내려받는다. 로그인·CAPTCHA·권한 제한을 우회하지 않는다. 자료 수는 제공자 갱신으로 바뀔 수 있다. 기존 파일을 바꾸지 말고 새 스냅샷을 받아 다시 감사한다.

### 실제 연결 감사 실행

### 수식·검사·실행 제한

세대당 주차는 주차대수/세대수, 승강기는 여섯 종류 합계/세대수다. 분모가 양수이고 필요한 원값이 있을 때만 산출한다. KAPT 12행은 세대 수 분모가 유효하지 않다. 21,793행의 유효 분모 중 승강기 비율495·최고층30·동수15가 결측이었다. 인구 전년동월 증가율은 정의만 있고 현재는 같은 코드의 비교 자격만 감사한다.

120개 자동검사와 독립 검토는 코드·파서·수식 경계를 확인했다. 원본 MOIS/KAPT/BOK의 재파싱도 저장 CSV와 대조했다. 모델 정확도·시간 이동 포함률이나 모든 오류 부재를 증명하지 않는다.

`feature_ready=false`와 `historical_availability_proven=false`를 준비 완료로 바꾸지 않는다. 과거 빈티지, 단지–좌표–시설 통합, 표본 정답 대조, 대출금리·물가·지수·미분양, 최종 비교 행렬 동결이 남아 있다. 메모리·시간의 실제 벤치마크도 하지 않았다. 4차의 확장 비교 실행기는 별도 `--execute`가 있어야 학습하지만 현재 중지 지시를 해제한 것은 아니다. 기존 8가설·15평가 수식은 유지하고 완성 논문·실측 성능은 아직 없다.

## LEVEL 4 - Advanced

### 모듈 경계와 데이터 계약

기존 모델 적합·가설 평가 코드는 보존하고 원천 처리 모듈을 분리했다. 신규 경로는 취득과 후보 연결의 기술 검증이다. **실제 모델 학습을 실행하지 않으며 준비 완료를 자동 부여하지 않는다.**

| 모듈 | 입력→출력 | 실패 경계 |
|---|---|---|
| `national_sources` | MOIS CP949 CSV/BOK HTML→정규화 CSV·영수증 | 요청 12개월·머리글·인구 불일치·금리 결정행 형식 변경 거부 |
| `kapt_source` | 공개 첨부 목록·XLSX→30개 선택 열·원행 번호 | 단지코드 중복·음수/범위 밖 문자열 참조·연구 열 수식 거부 |
| `complex_linkage` | 계약 주소·단지 후보→상태와 원단지 행 | 이름/지번/도로명 불일치·모호 상태를 유지 |
| `kapt_coordinates` | 지도 JSON 영수증·공식 JS→코드별 좌표 상태 | 원문/방법 SHA·지역 범위·검색월·투영 매개변수 검증 |
| 감사 스크립트 두 개 | 계약 manifest·정규화 원천→연도/시도 연결 집계 | 원본 SHA·행수·처리 중 변경 확인 |

수집기는 임시 폴더에 원응답·CSV·manifest를 완성한 뒤 새 폴더로 바꾼다. 실패한 취득을 정상 데이터 폴더로 남기지 않는다. 원본 XLSX를 재작성하지 않고 연락처·사업자번호 같은 불필요한 열은 연구용 CSV에 분리하지 않는다. 원본은 로컬에 보존한다.

### 지역·시점 결합

`population_before_month(records, region, day, lag_months=2)`는 계약월-2개월의 정상 행만 대상으로 이름의 토큰 경계를 확인한다. 가장 긴 일치 지역을 반환하되 같은 길이 복수 후보는 `AmbiguousPopulationError`다. 시도 대체는 반환된 이름의 수준으로 별도 집계한다. `rate_before_day(records, day)`는 결정일<계약일의 최댓값이며 당일 결정을 제외한다.

| 실제 인구 연결 | 계약 수 | 개발 시 해석 |
|---|---:|---|
| 시군구 수준 | 2,579,914 | 경계 불변 보증은 아님 |
| 시도 수준 | 61,674 | 세부 접근성 정보 대체 아님 |
| 미연결 | 186,126 | 다른 이름으로 자동 교정 금지 |
| 복수 계층 | 52,566 | 같은 인구여도 첫 코드 선택 금지 |

원천 총21,156지역×월 중 정상20,088·공란348·0인구/세대720행이다. 코드의 전신·분할·통합을 추측하지 않는다. `published_at`을 두 달 지연 가정으로 생성하지 않는다. 역사 빈티지와 정답 이용 가능 시각이 없으므로 기존 strict_asof 조건을 우회하지 않는다.

### 주소 연결과 파생 비율

KAPT 법정동주소 끝에 단지명이 정확히 있으면 그 접미사만 제거한다. 계약의 지역+번지와 단지명이 정확히 일치한 후보를 찾고, 같은 시도에서 원문 도로명까지 맞는지 검사한다. 후보 둘 이상은 모호, 도로명 불일치는 `address_disagreement`, 필수 키 공란/하이픈은 미완전 상태다. 원문 신규2,880,280행 중387,989행·3,162코드만 연결됐다. 최종 표본 정제나 수작업 정답 대조 전 감사이며 이름 유사도 최대화를 하지 않았다.

`derive_features`는 세대수를 양의 정수로 검증하고 세대당 주차·승강기 비율을 계산한다. 숫자처럼 보이는 `200.0`은 정수값일 때 허용한다. NaN/무한대/음수는 거부한다. 승강기 여섯 종류 중 하나라도 공란이면 비율은 결측이다. 최고층은 건축물대장상 값이 양수이면 우선하고 없거나0이면 일반 최고층을 확인한다. 실제 위치나 시설의 과거 상태를 보정해 주는 기능은 아니다.

유효 세대 분모는21,793행이며12행은 사용 불가다. 유효 분모에서도 승강기495·최고층30·동수15행은 결측이다. 인구 전년동월 증가율은 같은 코드·정상 두 월·양의 이전값을 요구하는 후보 식이며 현재 구현은 비교 가능 여부만 집계한다.

### 좌표 변환과 격리

공개 페이지에서 실제 map 경계16개를 읽어 순차 조회했다. 영수증의 지역과 요청 bjdCode가 일치해야 하고 모든 searchDate가 같은 유효YYYYMM이어야 한다. 원페이지와 공식 좌표 JS의 취득 해시를 대조한다. 현재 관측은202609검색24588원행·22641코드다.

| 코드 상태 | 판정 순서 | 관측 코드 수 |
|---|---|---:|
| invalid_coordinates | 비유한 수치·불완전 숫자·0,0 등 | 19 |
| missing_coordinates | 일부/전체 원좌표 누락 | 95 |
| conflicting_coordinates | 완전한 서로 다른 좌표가 둘 이상 | 1,320 |
| valid_current_map_point | 유일점 변환 성공·넓은 국내 범위 통과 | 21,207 |

같은 코드의 동일 점 반복은 한 점으로 검사하되 원행 수를 남긴다. 다른 점을 평균내거나 첫 점을 선택하지 않는다. 공식 JS `knew_fn_coordinate(flag=1)`의 PROJ 전체 문자열을 그대로 사용하며 주석의 EPSG 번호만 보고 대체하지 않는다. pyproj3.7.2·always_xy=True로 WGS84 경도/위도 순서를 고정한다. 출입구·보행거리·정밀 측량이라는 의미를 부여하지 않는다.

### 검증과 다음 변경의 영향

초기 독립 검토는 부분 금리 결정행이 누락되는 문제와 XLSX 음수 공유문자열 참조를 재현했다. 좌표 검토는 페이지/방법 해시 미검사와 검색월 하드코딩을 찾았다. 네 문제는 실패 회귀시험 후 수정했고 전체120검사가 통과했다. 실제 취득본에 해당 손상이 있었다는 관측과 구분한다. MOIS6원본·KAPT21805행·BOK63행을 재파싱해 정규화 값과 대조했으며 좌표 CSV도 독립 재변환 결과와 SHA가 같았다.

기존8가설15평가는 모델 예측 후의 확증 경로에 남아 있다. 확대 특징의 정보군 제거 비교는 탐색 경로이며 같은 알고리즘·계약을 비교한다. 현재 통합 특징은 미승인이다. 다음 변경에는 단지–좌표–시설 키, 물리적 역 ID, 미연결 편향, 추가 시장 통계, 과거 공표 원본, 비교 행렬 동결과 자원 벤치마크가 필요하다. 120검사 통과나 코드 관계 그래프는 실제 학습 성능·과거 상태 사실성·모든 오류 부재를 증명하지 않는다.

## LEVEL 5 - Expert

### 전문 검토의 판정 경계

이 차수는 자료 취득·보수적 결합·현재 좌표의 재현 가능한 기술 검증이다. feature_ready=false와 historical_availability_proven=false를 유지한다. 인구 증가율은 자격 감사만 있고 실제 특징값 파일은 없으며, 확대 특징을 기존8가설15평가에 통합하지 않았다. **정제 전 신규 분모와 최종 모델 표본을 분리한다.**

검사120개는 기존 모델 합성 기술검사와 새 파서·주소·좌표 회귀검사의 합계다. 독립 검토에서 네P2경계 오류를 재현·수정했고, 실제 MOIS6원본/KAPT/BOK 재파싱과 좌표 변환 결과를 대조했다. 기술 PASS를 과거 정보의 사실성·표본 대표성·실측 예측 성과로 확대하지 않는다.

| 추론 계층 | 현재 구현/근거 | 확정하지 못한 점 |
|---|---|---|
| 기본8가설15목표평가 | 기존 예측 결과에 사전 식 적용 | 실제 대규모 적합 결과 없음 |
| 확대정보 비교 | 동일 계약의 MAE 차이·정보군 제거 | 특징 스냅샷과 전체 실험 행렬 미동결 |
| 불확실성 | 기존 군집 부트스트랩·다중평가 조건 보존 | 시간/지역 이동의 정확 포함 보장 없음 |
| 원천 시간 | 대상 월·결정일·이번 취득 시각 | 당시 발표 원본·정답 공개 및 수정 빈티지 없음 |

기존 확증 경로는9999회단지군집 부트스트랩과15평가 Bonferroni 근사 구간을 사용하며 정확한 동시95%보장이라고 해석하지 않는다. 확대 정보군 비교의 점별95%군집 근사구간은 별도 탐색 결과다. 제안 복합손실 BC_loss는 검증되지 않은 보조 지표이고 적정점수·선택 기준·새 정리로 주장하지 않는다. 기존 가설·인용 문서의 범위를 유지한다.


실제 학습은 중지 상태다. 이번 차수는 공식 자료 취득·정규화·연결 감사이며, 예측 성능이나 가설 지지 결과가 아니다. 원본과 이전 차수는 보존한다.

### 실제 연결 감사

| 원문 신규 계약 연도 | 분모 | 인구 시군구 수준 연결 | 시도 수준 대체 연결 | 미연결 | 동일 지명 복수 계층 | KAPT 이름·지번·도로명 연결 |
|---|---:|---:|---:|---:|---:|---:|
| 2022 | 606,292 | 521,922 | 15,214 | 56,187 | 12,969 | 86,906 |
| 2023 | 732,312 | 650,805 | 17,470 | 51,906 | 12,131 | 101,347 |
| 2024 | 789,728 | 721,889 | 14,716 | 39,163 | 13,960 | 105,002 |
| 2025 | 751,948 | 685,298 | 14,274 | 38,870 | 13,506 | 94,734 |
| 합계 | 2,880,280 | 2,579,914 | 61,674 | 186,126 | 52,566 | 387,989 |

인구는 계약월에서 2개월을 뺀 월의 이름을 토큰 경계에 맞춰 연결했다. 같은 지명의 서로 다른 행정 계층은 자동 선택하지 않는다. 세종의 두 코드처럼 인구가 같아도 임의 합치지 않는다. 명칭이 달라진 지역도 자동 교정하지 않는다. 이것은 연결 자격 감사이며 최종 정제 표본의 매칭률이 아니다.

기준금리는 결정일이 계약일보다 앞선 값만 사용하도록 시험했다. 신규 계약 2,880,280행 모두 날짜상 과거 결정값이 존재했다. 이 값이 예측 성능을 높인다는 뜻은 아니다.

KAPT는 법정동주소 끝의 단지명을 정확히 분리하고 지번·단지명이 일치한 후보에서 도로명까지 확인했다. 3,162개 고유 단지 코드, 계약 387,989행(원문 신규의 약 13.47%)이 연결됐다. 동일 cluster_id가 서로 다른 KAPT 코드로 연결된 경우는 관측되지 않았다. 별칭·번지 말미 하이픈·행정구역 개편 등을 임의 정규화하지 않아 연결률이 낮다. 이 부분집합을 전국 대표 표본으로 주장할 수 없다. 표본 수작업 대조와 미연결 편향 평가가 남아 있다.

### 좌표 처리

| 검증 상태 | 단지 코드 수 | 처리 |
|---|---:|---|
| 유일하고 유효한 현재 지도점 | 21,207 | 현재 좌표 후보로 보존 |
| 서로 다른 좌표 충돌 | 1,320 | 대표점·평균점 선택 없이 격리 |
| 일부 또는 전체 좌표 누락 | 95 | 결측 보존 |
| 잘못된 수치 또는 원점 0,0 | 19 | 격리 |

일부 코드에는 좌표 누락과 충돌이 함께 있다. 표는 잘못된 수치→누락→충돌의 우선순위로 나눈 배타적 상태이며, 원좌표 쌍이 둘 이상인 전체 코드 수와 구분한다. 이 지도점이 단지 중심점·출입구·측량점인지는 증명되지 않았다. 실제 보행거리나 과거 개교·개통·시설 운영 상태로 해석하지 않는다.

공식 `knew_map.js`의 중앙원점 TM PROJ 문자열 전체를 그대로 보존하고 WGS84 경위도로 변환한다. 소스 주석의 EPSG 번호를 추측해 적용하지 않는다. pyproj 3.7.2 `Transformer.from_crs(..., always_xy=True)`로 경도·위도 순서를 고정한다. [공식 pyproj 문서](https://pyproj4.github.io/pyproj/stable/api/transformer.html)의 축 순서 조건을 따른다. 소수 자릿수는 실제 위치 정확도를 의미하지 않는다.

### 사전 수식과 사용 자격

| 수치 | 식 | 조건 |
|---|---|---|
| 인구 지연값 | P*(i,t) = P(g(i), month(t)-2) | 정확한 이름 연결. 2개월 지연은 연구상 가정이며 실제 공표 시각으로 저장하지 않음 |
| 인구 전년동월 증가율 후보 | 100 × [P(g,m)/P(g,m-12)-1] | 같은 코드, 두 시점 정상, 이전 인구>0. 개편된 코드의 전신을 추측하지 않음 |
| 세대당 주차 | 주차대수/세대수 | 세대 수>0. 현재 추출값에만 해석 가능 |
| 세대당 승강기 | 6종 승강기 합계/세대수 | 한 종류라도 미입력이면 결측. 0을 임의 대입하지 않음 |
| 기준금리 연결 | r(t)=r(s*), s*=max{s:s<t} | 계약일 당일 결정 제외. 관측된 발표 시각 증명은 별개 |

단지 자료 21,805행 중 유효한 세대 수 분모는 21,793행이고 12행은 사용 불가다. 분모가 유효한 행에서도 승강기 비율 495행, 최고층 30행, 동수 15행은 결측이다. 비정상값을 0으로 바꾸지 않는다. 인구 전년동월 식은 후보 정의이며 현재 코드는 같은 코드의 비교 가능 여부만 감사한다. 실제 증가율 특징 스냅샷은 아직 만들지 않았다.

위 식은 정의된 행정 통계의 지연·비율 계산이며 새로운 학술 정리나 검증된 신규 지표라고 주장하지 않는다. 기존 [8개 가설·15개 평가와 인용](논문_가설과_수식.md), [확장 정보군 비교 수식](확장분석_수식과해석.md)은 유지한다. 가설 결과는 실제 예측 후에만 산출한다.

### 재현 절차

Python 3.12에서 `requirements.txt`와 `requirements_acquire.txt`를 설치한다. 아래 명령은 취득·감사만 수행한다. 출력은 존재하지 않는 새 경로여야 한다. 기본정보 XLSX는 수정하지 않는다.

```powershell
python -m rentlab.national_sources population --year 2020 --output 새폴더/MOIS_2020
# 2021~2025도 각 연도를 별도 폴더로 취득
python -m rentlab.national_sources base-rate --output 새폴더/BOK
python -m rentlab.kapt_source --output 새폴더/KAPT
python scripts/collect_kapt_map.py --search-month 202609 --output 새폴더/지도원문
python -m rentlab.kapt_coordinates --raw-root 새폴더/지도원문 --output 새폴더/좌표검증
python scripts/audit_national_sources.py --project 프로젝트루트 --output 새감사.json
python scripts/audit_complex_linkage.py --project 프로젝트루트 --output 새단지감사.json
python -m unittest discover -s tests -v
```

두 감사 스크립트는 프로젝트 내 `실제 실험/확장 입력 1차`, `외부 자료/2차/MOIS_2020`~`MOIS_2025`, `BOK`, `KAPT_검증취득` 배치를 사용한다. 새 취득 경로의 이름을 이 배치에 맞추거나 스크립트의 명시된 입력 위치를 변경해야 한다. 원응답·해시·행수·취득 시각을 보존한다. 인증키 없이 접근되는 공식 공개 절차만 사용하고 CSRF 보호를 준수한다.
