# 새 연구 5차

전국 아파트 임대차 연구의 국내 자료 취득·주소 연결·좌표 검증을 보강했다. **실제 학습은 중지 상태이며 예측 성능은 아직 없다.**

| 추가 자료 | 실제 확보 | 검증 상태 |
|---|---:|---|
| 인구·세대 | 2020–2025 21,156 지역×월 | 원천 공란·0값·행정 계층 구분 |
| 기준금리 | 역사 변경 63행 | 결정일 당일 제외 연결 |
| 단지 기본정보 | 21,805개 단지 | 원본 엑셀과 연구용 30열 보존 |
| 공개 지도 | 24,588행·22,641코드 | 유일하고 유효한 현재 좌표 21,207코드 |
| 거래와 단지 연결 | 신규 계약 387,989행 | 전체 신규 2,880,280행의 약 13.47%, 전국 대표성 주장 불가 |
