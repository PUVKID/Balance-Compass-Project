# 새 연구 9차 변경 기록

양쪽 저장 summary 사전 대조 및 동일 바이트 보관, 홀드아웃 보정 원행 집합/관측값 대조를 추가했다. 새 회귀 검사3개와 전체171개 검사를 통과했다. 이전8차의 완료 가드·영어/읽기 수준 보완을 보존했다.

| 검증 경로 | 9차 처리 | 한계 |
|---|---|---|
| 양쪽 저장 summary | 반환값과 저장 JSON을 분석 폴더 생성 전에 대조 | 원자료의 과거 사실성을 인증하지 않음 |
| 홀드아웃 보정 계약 | 일반 보정 자료에서 서울 제외 후 원행 집합·관측값 일치 확인 | 예측값은 모델별 차이를 허용 |
| 회귀 검사 | 기존 168개에 3개 검사 추가, 총 171개 통과 | 제어 입력 검사이며 실제 학습 아님 |
| 연구 상태 | 8가설·15개 평가·분할·수식·문턱 유지 | 실제 학습 중지·성능 미측정 |
