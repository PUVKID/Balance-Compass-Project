# 9차 검증과 실행 안내

실제 학습 중지를 유지한다. Python 3.12·고정 requirements·Rust 금액 파서 환경에서 아래 명령은 제어 입력 검사만 실행한다.

```powershell
python -B -X utf8 -m unittest discover -s tests -v
```

결과: 171개 통과. 실제 데이터 학습은 실행하지 않았다. 기존 --manifest 입력 선택은 유지된다. --execute 없는 명령은 계획만 출력하며 중지를 해제하지 않는다.

| 검증 경로 | 9차 처리 | 한계 |
|---|---|---|
| 양쪽 저장 summary | 반환값과 저장 JSON을 분석 폴더 생성 전에 대조 | 원자료의 과거 사실성을 인증하지 않음 |
| 홀드아웃 보정 계약 | 일반 보정 자료에서 서울 제외 후 원행 집합·관측값 일치 확인 | 예측값은 모델별 차이를 허용 |
| 회귀 검사 | 기존 168개에 3개 검사 추가, 총 171개 통과 | 제어 입력 검사이며 실제 학습 아님 |
| 연구 상태 | 8가설·15개 평가·분할·수식·문턱 유지 | 실제 학습 중지·성능 미측정 |
