# 9차 저장 결과 대조 검증

8차 이후 저장 결과 통합 경로를 추가로 점검했다. 실제 학습이나 자료 취득은 실행하지 않았다. 8차 코드 완료 가드·두 회귀 검사와 한영 설명 보완(기준 9630bd0)을 보존한다.

## 재현한 누락과 수리

| 사례 | 수정 전 | 수정 후 |
|---|---|---|
| 일반 summary 누락·변경 | 반환값만으로 통합 진행 가능 | 분석 폴더 생성 전 ValueError |
| 홀드아웃 summary 누락·변경 | 복사 후에 발견되어 분석 폴더가 남음 | 양쪽 모두 사전 대조 |
| 홀드아웃 보정 원행 대체·누락 | 원행 중복·건수·시점이 맞으면 다른 계약도 통과 | 서울 제외 보정 행 집합과 정확히 대조 |
| 보정 정답·지역·날짜·단지 변경 | 개별 파일 형식 검사만 통과하면 허용 | 같은 원행의 관측값 불일치 거부 |
| 보정 행 순서·모델 예측 차이 | 허용 | 그대로 허용 |

experiment_runner.combine_results는 양쪽 summary를 읽어 반환값과 JSON 자료형까지 대조한 뒤 같은 바이트를 별도 복사본으로 보관한다. 일반 원본은 일반원본_summary.json, 홀드아웃 원본은 홀드아웃/summary.json에 저장하고 입력검증.json에 해시를 남긴다. 일반 복사본은 분석 결과 summary.json과 다른 파일이다. 원본 결과는 덮어쓰지 않는다.

research_metrics.write_research_results는 일반 보정 표에서 서울특별시 및 하위 지역을 제외하고 홀드아웃 보정 표와 source_row_id 집합을 대조한다. ID로 정렬한 뒤 정답(actual_won)은 유한 수치로, date·region·cluster_id는 문자열로 일치해야 한다. prediction_won은 학습 결과이므로 같은 값을 강제하지 않는다. 이는 기존 동일 입력 홀드아웃 조건의 구현 보강이며 새로운 과학 가설이나 배제 기준이 아니다.

## 직접 검증

새 검사 3개는 양쪽 summary 누락/변경/불리언 자료형 변경 6조건, 보정 원행 대체/누락 및 4개 관측 항목 변경 6조건과 정상 예측 변경/역순 입력을 검증한다. 수정 전 failures=7/errors=3을 관측했다. 누락 파일의 예외 종류와 늦은 실패 위치도 포함한다. 불리언 true와 숫자 1을 같게 보는 Python 사전 비교의 누락도 제어 입력에서 2개 오류로 재현해 JSON 자료형을 보존하는 비교로 수리했다. 최종 세 검사와 전체 171개 검사를 다시 실행했다. 기존 합성 제어 검사와 실제 적합을 구분한다. 이 차수는 484만 행 전수 감사를 다시 실행한 것으로 보고하지 않는다. 8차 전수 감사는 해당 시점 결과로 보존한다.

| 검증 경로 | 9차 처리 | 한계 |
|---|---|---|
| 양쪽 저장 summary | 반환값과 저장 JSON을 분석 폴더 생성 전에 대조 | 원자료의 과거 사실성을 인증하지 않음 |
| 홀드아웃 보정 계약 | 일반 보정 자료에서 서울 제외 후 원행 집합·관측값 일치 확인 | 예측값은 모델별 차이를 허용 |
| 회귀 검사 | 기존 168개에 3개 검사 추가, 총 171개 통과 | 제어 입력 검사이며 실제 학습 아님 |
| 연구 상태 | 8가설·15개 평가·분할·수식·문턱 유지 | 실제 학습 중지·성능 미측정 |

## 여전히 미입증인 사항

단지 미상 31행, 독립 위치 정답, 시설·인구·임대차 자료의 계약 당시 판본과 공개 시점, 실제 대규모 자원·성능은 이번 수리로 해결되지 않는다. 가짜 ID·사후 삭제·출처 없는 수치 보정은 수행하지 않았다. 학습 중지 상태를 유지하며 논문 가설 지지나 연구 전체 완료를 주장하지 않는다. [8차 자료 감사](8차_전수검증.md), [수식·인용](논문_가설과_수식.md), [직전 비교](차수비교.md).
