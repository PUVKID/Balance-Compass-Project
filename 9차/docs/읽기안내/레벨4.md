# LEVEL 4 - Advanced

combine_results는 두 summary를 분석 디렉터리 생성 전에 대조하고 읽은 동일 바이트를 복사한다. 보정 집합은 source_row_id 인덱스로 정렬해 비교하므로 순서를 강제하지 않는다. 원본 일반 summary와 분석 summary를 다른 이름으로 보관한다.

| 모듈 계약 | 비교 방법 | 보존 파일 |
|---|---|---|
| combine_results | JSON 자료형을 구분하는 정렬 직렬화 비교 | 일반원본_summary.json, 홀드아웃/summary.json |
| write_research_results | source_row_id 집합 비교 후 ID 정렬 | 각 보정 CSV의 실제 읽은 바이트 해시 |
| 관측 열 | 문자열3개·정답 수치의 동일성 | date·region·cluster_id·actual_won |
| 학습 산출 열 | 동일값 강제 안 함 | prediction_won의 별도 추정 허용 |
