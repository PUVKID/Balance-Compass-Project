## LEVEL 1 - Beginner

### 저장 결과의 이름표 확인

실험 결과 상자의 이름표와 상자 안의 기록이 같은지 양쪽 모두 확인한다. 서로 다른 계약의 보정 자료가 섞이면 계산 전에 멈춘다. 검사 통과가 실제 예측 성능을 뜻하지는 않는다.

| 쉬운 상황 | 확인하는 것 | 결과 |
|---|---|---|
| 상자의 이름표와 내용이 다름 | 결과 요약과 저장 기록 | 계산 전에 중단 |
| 다른 계약이 섞임 | 같은 계약 번호인지 | 잘못된 비교 거부 |
| 새 모델의 예측이 달라짐 | 관측 계약은 그대로인지 | 정상 비교 허용 |

## LEVEL 2 - Explorer

### 같은 계약을 따라 대조

일반 보정 계약에서 서울 계약만 제외한 집합이 홀드아웃 보정 계약과 같아야 한다. 계약 번호·정답·날짜·지역·단지는 같아야 하고 별도 모델의 예측값은 달라도 된다.

| 자료 흐름 | 남겨야 할 것 | 달라도 되는 것 |
|---|---|---|
| 일반 보정 → 서울 제외 | 나머지 계약 번호 전체 | 행의 나열 순서 |
| 일반 ↔ 홀드아웃 관측 | 실제 금액·계약일·지역·단지 | 별도 모델의 예측 |
| 요약 → 분석 복사본 | 값과 JSON 자료형·검사한 바이트 | 분석 결과용 파일 이름 |

## LEVEL 3 - Practitioner

### 실행과 오류 확인

Python 3.12와 고정 의존성 및 Rust 파서 환경에서 python -B -X utf8 -m unittest discover -s tests -v로 제어 검사를 실행한다. 171개 통과를 관측했다. summary 불일치와 보정 집합/관측값 불일치는 ValueError로 중단한다. 실제 학습 명령은 실행하지 않았다.

| 실행 단계 | 확인 위치 | 오류 처리 |
|---|---|---|
| 제어 검사 | unittest discover, 총171개 | 실패하면 완료 처리하지 않음 |
| 통합 전 | 양쪽 summary.json | 누락·값/자료형 불일치 거부 |
| 보정 대조 | calibration_predictions.csv | 집합·관측 불일치 ValueError |
| 결과 추적 | 입력검증.json, 일반원본_summary.json | 원본 결과와 별도 보관 |

## LEVEL 4 - Advanced

### 저장 바이트와 관측 키 연결

combine_results는 두 summary를 분석 디렉터리 생성 전에 대조하고 읽은 동일 바이트를 복사한다. 보정 집합은 source_row_id 인덱스로 정렬해 비교하므로 순서를 강제하지 않는다. 원본 일반 summary와 분석 summary를 다른 이름으로 보관한다.

| 모듈 계약 | 비교 방법 | 보존 파일 |
|---|---|---|
| combine_results | JSON 자료형을 구분하는 정렬 직렬화 비교 | 일반원본_summary.json, 홀드아웃/summary.json |
| write_research_results | source_row_id 집합 비교 후 ID 정렬 | 각 보정 CSV의 실제 읽은 바이트 해시 |
| 관측 열 | 문자열3개·정답 수치의 동일성 | date·region·cluster_id·actual_won |
| 학습 산출 열 | 동일값 강제 안 함 | prediction_won의 별도 추정 허용 |

## LEVEL 5 - Expert

### 추론 조건과 구현 검증 구분

같은 원천 manifest·설정이라는 선언만으로 결과 보정 행의 동일성을 대신하지 않는다. 이 수리는 H5 비교 입력의 추적성을 강화하지만 단지 간 독립성·시간 교환가능성·인과 일반화를 증명하지 않는다. 기존 8가설·15개 평가 및 다중평가 구간 조건은 유지하며 미입증 역사판과 군집 결손은 그대로 보고한다.

| 연구 조건 | 9차가 확인하는 범위 | 입증하지 않는 범위 |
|---|---|---|
| H5 비교 입력 | 서울 제외 보정 모집합과 관측 키 동일성 | 지역 이동의 인과적 효과 |
| 분석 추적성 | 반환 요약·저장 JSON·복사 해시 연결 | 역사판과 원천 자료의 사실성 |
| 불확실성 | 기존 단지 bootstrap·15평가 규칙 유지 | 시간/군집 독립성과 포함률 보장 |
| 실측 주장 | 제어 검사만171개 통과 | 실제 성능·가설 지지·논문 완료 |
